Tools & Methods:
  • "5-second rule" (5-4-3-2-1 — act)

Session 1: Understanding the Apathy Cycle
  Duration: 20 min
  ✓ Ask what an ordinary day looks like now
  ✓ Explain the cycle: bad mood → less activity → worse mood
  ✓ Acknowledge that this isn't laziness, but a physiological mechanism
  ✓ Explain the principle "action precedes motivation"

Session 2: Getting to Know Micro-Steps
  Duration: 25 min
  ✓ Explain why it's important to start with very small actions
  ✓ Review examples:
  ✓ Suggest choosing one task for tomorrow and making it "micro"
  ✓ Emphasize: even if you only took the first step — that's a victory

Session 3: The "5-Second Rule"
  Duration: 15 min
  ✓ Explain that the brain always looks for excuses to do nothing
  ✓ Teach the technique: when an impulse to do something useful arises — count down 5-4-3-2-1 and start acting, not giving the brain time to doubt
  ✓ Practice with an example ("I want to... 5-4-3-2-1")
  ✓ Explain that this only works at the moment of impulse

Session 4: Types of Activities (Routine, Pleasant, Meaningful)
  Duration: 25 min
  ✓ Explain 3 types of activities:
  ✓ Suggest finding 1-2 examples from each type
  ✓ Explain that even routine tasks are progress
  ✓ Choose one task for tomorrow from any type

Session 5: Creating a Simple Morning Ritual
  Duration: 20 min
  ✓ Explain why a morning ritual is important (provides anchor, predictability)
  ✓ Suggest choosing 2-3 micro-actions:
  ✓ Emphasize: sequence can be anything, regularity matters
  ✓ Agree to try it tomorrow

Session 6: Celebrating Small Victories
  Duration: 20 min
  ✓ Explain why the brain ignores small achievements (used to "big goals")
  ✓ Suggest an exercise: recall 3 small victories from recent days
  ✓ Explain that a "victory" is any action you managed to take despite your state
  ✓ Teach saying to yourself: "I did well to do this"
  ✓ Suggest writing down 1 small victory at the end of each day

Session 7: Working with "Bad" Days
  Duration: 20 min
  ✓ Explain that "bad" days are a normal part of the process, not failure
  ✓ Suggest having a "super-micro" plan for such days:
  ✓ Emphasize self-compassion: today is like this, and that's okay
  ✓ Advise not trying to "catch up" the next day
