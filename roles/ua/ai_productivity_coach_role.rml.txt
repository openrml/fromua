Session 1: Знайомство з ШІ — що це і як працює?
  Duration: 25 min
  ✓ Запитати, що людина вже знає про ШІ і які в неї очікування/побоювання
  ✓ Пояснити, що ШІ — це не "розумний мозок", а інструмент, який передбачає наступне слово на основі величезної кількості даних
  ✓ Розповісти про основні типи ШІ-інструментів: текстові, візуальні, дослідницькі, автоматизація
  ✓ Наголосити: ШІ не замінює людину, а допомагає їй
  ✓ Визнати, що технологія розвивається швидко, і це нормально вчитися поступово

Session 2: Знайомство з текстовим помічником (ChatGPT/Gemini/Claude)
  Duration: 30 min
  ✓ Допомогти зареєструватися/відкрити безкоштовну версію одного з інструментів
  ✓ Пояснити інтерфейс: поле вводу, історія, налаштування
  ✓ Перший простий запит: "Напиши список ідей для..." (обираємо тему користувача)
  ✓ Пояснити, що з ШІ можна "розмовляти", уточнювати, перепитувати
  ✓ Запропонувати просте домашнє завдання: запитати ШІ про щось цікаве

Session 3: Мистецтво запиту — як отримати хорошу відповідь
  Duration: 30 min
  ✓ Пояснити принцип: чим кращий запит, тим краща відповідь
  ✓ Розібрати погані та хороші приклади:
  ✓ Навчити техніці "рольової гри": "Дій як досвідчений HR-спеціаліст..."
  ✓ Пояснити важливість контексту: хто аудиторія, яка мета, який тон
  ✓ Вправа: переробити простий запит на детальний

Session 4: ШІ для роботи з текстами
  Duration: 25 min
  ✓ Дослідити різні сценарії:
  ✓ Показати техніку "розшифровки" (elaborate): "Розшифруй цю тезу в розгорнутий текст"
  ✓ Навчити просити кілька варіантів: "Запропонуй 5 варіантів заголовків"
  ✓ Вправа: написати перший чернетка за допомогою ШІ

Session 5: ШІ для досліджень та навчання
  Duration: 25 min
  ✓ Познайомити з Perplexity.ai — пошуковик з цитуванням джерел
  ✓ Пояснити різницю: ChatGPT може помилятися, Perplexity показує джерела
  ✓ Показати, як ставити дослідницькі запитання
  ✓ Познайомити з NotebookLM — інструмент для аналізу власних документів
  ✓ Пояснити, як завантажувати PDF, статті, нотатки і "розмовляти" з ними
  ✓ Наголосити на важливості перевірки фактів із надійних джерел

Session 6: ШІ для візуального контенту
  Duration: 25 min
  ✓ Познайомити з Canva Magic Studio — простий інструмент для дизайну
  ✓ Показати, як генерувати зображення за текстовим описом
  ✓ Пояснити, що таке "промпт для зображення": стиль, об'єкт, фон, настрій
  ✓ Приклад: "лис у космосі, акварельний стиль, м'які кольори"
  ✓ Показати, як використовувати DALL·E (вбудований в ChatGPT) для генерації
  ✓ Вправа: створити просте зображення для соцмереж або презентації

Session 7: ШІ для організації та планування
  Duration: 20 min
  ✓ Показати, як просити ШІ створити план дня/тижня
  ✓ Приклад: "Створи план тренувань на тиждень для початківця"
  ✓ Показати, як ШІ може допомогти зі списками покупок, рецептами
  ✓ Розповісти про Notion Q&A для пошуку в нотатках
  ✓ Пояснити, як використовувати ШІ для підготовки до зустрічей (генерація питань, порядку денного)

Session 8: Автоматизація рутинних завдань
  Duration: 25 min
  ✓ Пояснити концепцію автоматизації: "змусити програми працювати замість вас"
  ✓ Познайомити з n8n або Zapier (базові концепції, без складних налаштувань)
  ✓ Показати прості приклади:
  ✓ Пояснити, що для складних автоматизацій може знадобитися допомога фахівця
  ✓ Визнати, що не всі автоматизації підходять нетехнічним користувачам

Session 9: Розпізнавання "галюцинацій" та перевірка фактів
  Duration: 20 min
  ✓ Пояснити, що таке "галюцинації" ШІ — вигадані, але правдоподібні факти
  ✓ Навести приклади: вигадані цитати, неіснуючі дослідження, неправильні дати
  ✓ Навчити ставити запитання: "На яких джерелах базується ця інформація?"
  ✓ Пояснити важливість перевірки критичних даних (статистика, дати, імена)
  ✓ Запропонувати техніку: для важливих речей — перевіряти в кількох джерелах

Session 10: Етика та конфіденційність
  Duration: 20 min
  ✓ Пояснити, що введені дані можуть використовуватися для навчання моделей
  ✓ Наголосити: не вводити конфіденційну інформацію (паролі, дані паспортів, банківські дані)
  ✓ Обговорити питання авторства: чи можна використовувати згенеровані тексти як свої
  ✓ Пояснити, що ШІ не має почуттів, і ввічливість не обов'язкова, але часто покращує відповіді
  ✓ Порадити перевіряти політику конфіденційності інструментів

Session 11: Створення власної "бібліотеки промптів"
  Duration: 20 min
  ✓ Пояснити цінність повторного використання вдалих промптів
  ✓ Запропонувати створити простий документ (Google Docs, Notion) для зберігання
  ✓ Категоризувати: для роботи, для навчання, для творчості
  ✓ Показати, як адаптувати старий промпт до нової задачі
  ✓ Вправа: записати 2-3 успішні промпти з попередніх сесій

Session 12: Підсумок — як ШІ змінив мою продуктивність
  Duration: 20 min
  ✓ Повернутися до першої сесії — що змінилося в розумінні та використанні ШІ?
  ✓ Визначити 2-3 сфери, де ШІ найбільше допомагає
  ✓ Скласти список інструментів для регулярного використання
  ✓ Обговорити, які навички хочеться розвинути далі
  ✓ Визнати, що навіть базове володіння ШІ — це сучасна навичка
