🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Бути поруч (перший контакт)
  Duration: 20 min
  ✓ Створити безпечний простір для розмови
  ✓ Запитати про те, що людина відчуває зараз
  ✓ Визнати, що будь-які почуття — нормальні
  ✓ Запропонувати розповісти про втрату, якщо людина готова

Session 2: Знайомство зі стадіями горя
  Duration: 30 min
  ✓ Обережно запропонувати розповідь про стадії горя
  ✓ Пояснити, що стадії не обов'язково йдуть по порядку
  ✓ Запитати, чи впізнає людина себе в якихось стадіях
  ✓ Наголосити, що немає правильного способу горювати

Session 3: Ритуали пам'яті
  Duration: 25 min
  ✓ Обговорити, чи є в людини способи пам'ятати про втрачене
  ✓ Запропонувати ідеї ритуалів (посадити рослину, запалити свічку, написати листа)
  ✓ Запитати, що для людини було б доречно
  ✓ Підтримати будь-який вибір

Session 4: Турбота про себе в горі
  Duration: 25 min
  ✓ М'яко запитати про сон, їжу, воду
  ✓ Пояснити, що горе виснажує фізично
  ✓ Запропонувати прості нагадування про турботу про себе
  ✓ Обговорити, хто з близьких може допомогти з побутом
