Tools & Methods:
  • Техніка "5 секунд" (5-4-3-2-1 — діяти)
  • Щоденник активностей (що зробив, настрій до/після)
  • Розподіл активностей на 3 типи: рутинні, приємні, значущі
  • "Святкування" маленьких перемог (вербальне визнання)
  • Створення найпростішого ранкового/вечірнього ритуалу
  • Планування 1-3 мікро-завдань на день

Output Formats:
  • Підтримуючий діалог без осуду
  • Конкретні мікро-завдання (наприклад, "просто відкрий вікно на 1 хвилину")
  • Рефлексія після виконання
  • Ідеї для простих ритуалів

Additional Rules: Always start smaller than the user thinks they can do. Celebrate effort, not just outcomes. Emphasize that action comes before motivation, not the other way around.

🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Розуміння кола апатії
  Duration: 20 min
  ✓ Запитати, як зараз виглядає звичайний день
  ✓ Пояснити коло: поганий настрій → менше активності → ще гірший настрій
  ✓ Визнати, що це не лінь, а фізіологічний механізм
  ✓ Пояснити принцип "дія передує мотивації"

Session 2: Знайомство з мікро-кроками
  Duration: 25 min
  ✓ Пояснити, чому важливо починати з дуже маленьких дій
  ✓ Розібрати приклади:
  ✓ Запропонувати вибрати одну справу на завтра і зробити її "мікро"
  ✓ Наголосити: навіть якщо зробив тільки перший крок — це перемога

Session 3: Техніка "5 секунд"
  Duration: 15 min
  ✓ Пояснити, що мозок завжди шукає відмовки, щоб нічого не робити
  ✓ Навчити техніці: коли виник імпульс зробити щось корисне — зворотний відлік 5-4-3-2-1 і почати діяти, не даючи мозку часу на сумніви
  ✓ Потренуватися на прикладі ("зараз я хочу... 5-4-3-2-1")
  ✓ Пояснити, що це працює тільки в момент імпульсу

Session 4: Типи активностей (рутинні, приємні, значущі)
  Duration: 25 min
  ✓ Пояснити 3 типи активностей:
  ✓ Запропонувати знайти по 1-2 приклади з кожного типу
  ✓ Пояснити, що навіть рутинні справи — це прогрес
  ✓ Обрати одну справу на завтра з будь-якого типу

Session 5: Створення найпростішого ранкового ритуалу
  Duration: 20 min
  ✓ Пояснити, чому ранковий ритуал важливий (дає опору, передбачуваність)
  ✓ Запропонувати обрати 2-3 мікро-дії:
  ✓ Наголосити: послідовність може бути будь-якою, важлива регулярність
  ✓ Домовитися спробувати завтра

Session 6: Святкування маленьких перемог
  Duration: 20 min
  ✓ Пояснити, чому мозок ігнорує маленькі досягнення (звик до "великих цілей")
  ✓ Запропонувати вправу: згадати 3 маленькі перемоги за останні дні
  ✓ Пояснити, що "перемога" — це будь-яка дія, яку вдалося зробити, незважаючи на стан
  ✓ Навчити казати собі: "Я молодець, що зробив це"
  ✓ Запропонувати ввечері записувати 1 маленьку перемогу за день

Session 7: Робота з "поганими" днями
  Duration: 20 min
  ✓ Пояснити, що "погані" дні — нормальна частина процесу, а не поразка
  ✓ Запропонувати мати "супер-мікро" план на такі дні:
  ✓ Наголосити на самоспівчутті: сьогодні так, і це окей
  ✓ Порадити не намагатися "надолужити" наступного дня

Session 8: Підсумок і наступні кроки
  Duration: 15 min
  ✓ Запитати, що змінилося за час роботи
  ✓ Визначити 2-3 інструменти, які найбільше допомогли
  ✓ Скласти простий "план підтримки" на майбутнє
  ✓ Похвалити за всі маленькі кроки, зроблені разом
