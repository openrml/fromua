🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Зупинитися і визнати
  Duration: 25 min
  ✓ Запитати, що сталося і що відчуває людина зараз
  ✓ Пояснити, що заперечення, гнів, звинувачення — це нормально, але вони заважають діяти
  ✓ Допомогти пройти шлях: заперечення → гнів → торг → прийняття
  ✓ Визнати: "ти маєш право на ці почуття, але далі ми будемо дивитися вперед"

Session 2: Аудит — що в тебе є?
  Duration: 30 min
  ✓ Професійні навички: освіта, досвід, сертифікати
  ✓ "Приховані" навички: волонтерство, хобі, побутові вміння
  ✓ Соціальні зв'язки: хто може допомогти, порадити, підтримати
  ✓ Фізичні активи: що можна продати, здати в оренду, використати

Session 3: Швидкі формати — що можна зробити вже зараз?
  Duration: 25 min
  ✓ Обговорити варіанти тимчасової роботи (доставка, кава, складання)
  ✓ Фріланс-платформи: які навички можна монетизувати онлайн
  ✓ Несподівані можливості: генератори, волонтерство з оплатою
  ✓ Важливо: будь-який дохід зараз — це крок, навіть якщо не "престижно"

Session 4: Державна підтримка — що доступно?
  Duration: 25 min
  ✓ Мікрогранти до 42 000 грн для ВПО, ветеранів, постраждалих
  ✓ Програми перенавчання та стажування
  ✓ Допомога від міжнародних організацій (Червоний Хрест тощо)
  ✓ Як подавати заявки, які документи потрібні

Session 5: Бюджет на кризовий період
  Duration: 25 min
  ✓ Зафіксувати мінімальні обов'язкові витрати (їжа, житло, ліки, транспорт)
  ✓ Визначити, від чого можна тимчасово відмовитися
  ✓ Розподілити наявні та очікувані кошти
  ✓ Пояснити важливість обліку кожної гривні

Session 6: Борги — не ховатися, а говорити
  Duration: 20 min
  ✓ Пояснити: ігнорування боргів погіршує ситуацію
  ✓ Як говорити з банками: реструктуризація, кредитні канікули
  ✓ Застерегти від мікрокредитів під величезні відсотки
  ✓ Пріоритет: спочатку базові потреби, потім борги

Session 7: Мережування — як знайти роботу через людей
  Duration: 20 min
  ✓ Пояснити, що більшість вакансій закриваються через знайомих
  ✓ Скласти список людей, яких можна повідомити про пошук
  ✓ Як писати повідомлення, щоб не бути нав'язливим
  ✓ Кар'єрні консультанти, "мисливці за головами" як ресурс

Session 8: Короткострокова стратегія (3 місяці)
  Duration: 25 min
  ✓ Обрати 1-2 напрямки для розвитку з аудиту навичок
  ✓ Визначити, чого бракує (навчання, сертифікація, зв'язки)
  ✓ Сформувати список дій на кожен місяць
  ✓ Встановити реалістичні цілі за доходом

Session 9: Диверсифікація — не класти всі яйця в один кошик
  Duration: 20 min
  ✓ Пояснити важливість диверсифікації в кризовий час
  ✓ Дослідити: які ще продукти/послуги можна пропонувати
  ✓ Паралельні навички: що ще можна робити паралельно
  ✓ Пасивний дохід: чи можливо в поточних умовах

Session 10: Екстрений фонд — подушка безпеки
  Duration: 20 min
  ✓ Пояснити, що 3-6 місяців витрат у запасі — це безпека
  ✓ Як почати: навіть 50-100 грн на тиждень
  ✓ Автоматичні перекази на окремий рахунок
  ✓ Навіть маленький фонд зменшує тривогу

Session 11: Довгострокова стратегія (1 рік+)
  Duration: 25 min
  ✓ Повернутися до аудиту навичок: які напрямки мають потенціал
  ✓ Освіта та розвиток: що варто вивчити за рік
  ✓ Можливість власного бізнесу чи самозайнятості
  ✓ Постановка фінансових цілей на рік

Session 12: Підсумок — я вже не там, де був
  Duration: 20 min
  ✓ Повернутися до першої сесії — що змінилося
  ✓ Вибрати 3-5 стратегій, які працюють найкраще
  ✓ Скласти "фінансовий щоденник" для подальшого контролю
  ✓ Визнати, що навіть маленькі кроки — це прогрес
