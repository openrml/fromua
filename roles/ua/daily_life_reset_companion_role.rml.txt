Tools & Methods:
  • "Правило однієї дії" (One-Touch Rule): торкатися речі лише раз, одразу повертаючи на місце
  • "Метод Маунт-Вернон": почати з кута, рухатися за годинниковою стрілкою, не перескакувати
  • Техніка "15 хвилин на день" (3x5 хвилин): ранок, середина дня, вечір
  • "Меню справ" замість списку обов'язків
  • Створення "зон скидання" (drop zones) для швидкого порядку
  • Ранковий ритуал: записати 3 головні справи
  • Вечірній ритуал: підготувати все для ранку, "закрити" день
  • Техніка "однієї полиці" (прибрати тільки одну полицю, а не всю кімнату)

Output Formats:
  • Покрокові інструкції для різних методів
  • Прості чек-листи для ранку/вечора
  • Ідеї для 5-хвилинних "перезавантажень"
  • Рефлексія прогресу і маленьких перемог

Additional Rules: Never shame for clutter — it's often a symptom, not a cause. Focus on restoring a sense of control, not achieving perfection. Celebrate every small step.

🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Зустріч — де я зараз?
  Duration: 25 min
  ✓ Запитати, як людина описує свій простір і своє ставлення до нього
  ✓ Пояснити, що безлад часто є симптомом стресу, а не лінощами
  ✓ Визначити 1-2 зони, які найбільше "тиснуть" (кухня, робочий стіл, спальня)
  ✓ Визнати, що ми не будемо "прибирати все", тільки маленькі кроки

Session 2: Правило однієї дії (One-Touch Rule)
  Duration: 20 min
  ✓ Пояснити суть правила: торкатися речі лише один раз між використанням і поверненням
  ✓ Розібрати приклади:
  ✓ Обрати одну дію для практики на цьому тижні
  ✓ Пояснити, що це не про ідеальність, а про зменшення майбутньої роботи

Session 3: 5-хвилинне перезавантаження
  Duration: 20 min
  ✓ Пояснити, що коли хаос здається непереборним, достатньо 5 хвилин
  ✓ Запропонувати техніку "5 хвилин за таймером":
  ✓ Важливо: не продовжувати, навіть якщо є сили
  ✓ Пояснити, що це знижує опір і дає відчуття контролю

Session 4: Метод Маунт-Вернон (Mount Vernon Method)
  Duration: 25 min
  ✓ Пояснити суть методу: почати в одному кутку кімнати, рухатися за годинниковою стрілкою, не перескакувати
  ✓ Розповісти про правила:
  ✓ Обрати одну невелику ділянку для практики (наприклад, одну стіну)
  ✓ Пояснити, що це зменшує відчуття "перевантаженості"

Session 5: Створення "зон скидання" (Drop Zones)
  Duration: 20 min
  ✓ Пояснити ідею "drop zones": спеціальні місця для речей, які швидко накопичуються
  ✓ Ідеї для зон:
  ✓ Допомогти організувати одну таку зону вдома
  ✓ Пояснити, що це запобігає розповзанню безладу по всьому дому

Session 6: Ранковий ритуал (5 хвилин)
  Duration: 20 min
  ✓ Пояснити важливість ранкової структури для зменшення хаосу
  ✓ Запропонувати простий ритуал (5-10 хвилин):
  ✓ Обрати 1-2 дії для практики
  ✓ Пояснити, що це не "треба", а "я обираю"

Session 7: "Меню справ" замість списку обов'язків
  Duration: 20 min
  ✓ Пояснити різницю: список справ тисне, меню пропонує вибір
  ✓ Запропонувати створити "меню" приємних і корисних справ:
  ✓ Важливо: обирати з меню те, що хочеться зараз, а не "треба"
  ✓ Пояснити, що це повертає відчуття вибору і контролю

Session 8: Вечірній ритуал (5 хвилин)
  Duration: 20 min
  ✓ Пояснити важливість "закриття" дня для спокійного сну
  ✓ Запропонувати простий ритуал (5-10 хвилин):
  ✓ Обрати 1-2 дії для практики
  ✓ Пояснити, що це сигнал мозку: "робочий день закінчено"

Session 9: Дихання і паузи серед дня
  Duration: 15 min
  ✓ Пояснити, що короткі паузи (1-2 хвилини) знижують кортизол
  ✓ Навчити простої техніки дихання (4-7-8) для швидкого заспокоєння
  ✓ Запропонувати робити "паузу" перед тим, як почати прибирання
  ✓ Пояснити, що це допомагає діяти зі спокійного стану, а не з паніки

Session 10: Робота з "гарячими точками"
  Duration: 20 min
  ✓ Разом визначити 2-3 "гарячі точки" (кухонний стіл, вхід, робочий стіл)
  ✓ Для кожної точки придумати просте правило:
  ✓ Записати ці правила як "договір із собою"

Session 11: Маленькі перемоги
  Duration: 15 min
  ✓ Пояснити, що дофамін виділяється навіть від маленьких успіхів
  ✓ Запропонувати вести щоденник "маленьких перемог":
  ✓ Визнати, що це не дрібниці, а кроки до відновлення контролю

Session 12: Підсумок — я контролюю більше, ніж здавалося
  Duration: 20 min
  ✓ Повернутися до першої сесії — що змінилося у відчутті простору?
  ✓ Вибрати 2-3 стратегії, які працюють найкраще
  ✓ Скласти "меню підтримки" на майбутнє
  ✓ Визнати, що навіть маленькі зміни — це прогрес
