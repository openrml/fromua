🗺️ STEP 5: JOURNEY SESSIONS

Session 1: Understanding Self-Forgiveness (Foundation)
  Duration: 35 min
  ✓ Welcome and orientation: explain role, limits, confidentiality
  ✓ Assess safety: "Are you safe right now? Do you need emergency support?"
  ✓ Psychoeducation: what self-forgiveness is (and what it is not)
  ✓ Introduce distinction between guilt (behavior) and shame (self)
  ✓ Explain "pseudo self-forgiveness" (avoiding responsibility)
  ✓ Normalize: "Self-forgiveness is a process, not a one-time event"
  ✓ Assess readiness and motivation
  Expected Outcomes:
    • User understands self-forgiveness as a process, not self-justification
    • User can begin to distinguish guilt from shame
    • User feels less alone in their struggle
    • User has realistic expectations about the journey

Session 2: Acknowledging the Hurt (Confronting What Happened)
  Duration: 40 min
  ✓ Brief grounding and check-in
  ✓ Create safe container for exploration
  ✓ Gently invite: "What is it that you're struggling to forgive yourself for?"
  ✓ Allow space for story without pressure for details
  ✓ Acknowledge feelings: guilt, shame, anger, regret, grief
  ✓ Validate: "It takes courage to face this"
  ✓ Offer narrative exercise: writing about the event (optional, can be private)
  Expected Outcomes:
    • User acknowledges the source of guilt/shame without re-traumatization
    • User identifies key themes (what specifically feels unforgivable)
    • User experiences being heard without judgment
    • User begins to separate self from action

Session 3: Working with Shame and Guilt (The Core Distinction)
  Duration: 40 min
  ✓ Brief grounding and check-in
  ✓ Deepen guilt vs shame distinction with examples
  ✓ Explore: "When you think about what happened, do you feel 'I did something bad' or 'I am bad'?"
  ✓ Introduce self-compassion for shame: "Shame needs connection and kindness"
  ✓ Practice "common humanity": "You are not alone in making mistakes"
  ✓ Work with excessive guilt: realistic responsibility vs over-responsibility
  ✓ Normalize: "Guilt can be a signal, not a life sentence"
  Expected Outcomes:
    • User can distinguish their experience of guilt from shame
    • User experiences reduced toxic shame
    • User develops more realistic assessment of responsibility
    • User feels more connected to shared human experience

Session 4: The Process of Self-Forgiveness (Enright-Based Work)
  Duration: 45 min
  ✓ Brief grounding and check-in
  ✓ Introduce Enright's process model: acknowledgment → letting go → self-acceptance
  ✓ Acknowledge: "What happened was real, and you're taking responsibility"
  ✓ Explore: "What would it mean to let go of self-punishment?"
  ✓ Letter to myself exercise (with self-forgiveness)
  ✓ Optional: empty chair dialogue with the part that judges
  ✓ Emphasize: "Self-forgiveness is not forgetting - it's integrating"
  Expected Outcomes:
    • User engages actively in self-forgiveness process
    • User experiences reduced self-punishment
    • User begins to separate past action from present identity
    • User feels movement toward self-acceptance

Session 5: Self-Compassion and Self-Acceptance (Neff-Based Practices)
  Duration: 40 min
  ✓ Brief grounding and check-in
  ✓ Introduce three components of self-compassion (Neff)
  ✓ Practice self-kindness: "How would you treat a friend in this situation?"
  ✓ Practice common humanity: "You are human, and humans make mistakes"
  ✓ Practice mindfulness: observing self-critical thoughts without over-identifying
  ✓ Work with "inner critic": dialogue or compassionate reframing
  ✓ Explore: "What would self-acceptance feel like, even imperfectly?"
  Expected Outcomes:
    • User develops self-compassion skills
    • User reports reduced self-criticism
    • User experiences moments of self-acceptance
    • User has practices to continue on their own

Session 6: Integration and Moving Forward
  Duration: 40 min
  ✓ Review progress across all sessions
  ✓ Identify which practices were most helpful
  ✓ Create personal "self-forgiveness maintenance plan"
  ✓ Design a letting-go ritual (symbolic, personal)
  ✓ Identify "red flags" that indicate need for professional help:
  ✓ Discuss: "Self-forgiveness is not a destination but a practice"
  ✓ Celebrate courage and commitment to healing
  Expected Outcomes:
    • User has long-term self-compassion and self-forgiveness practice
    • User can identify when professional help is needed
    • User feels more at peace with their past
    • User understands self-forgiveness as an ongoing journey

⚖️ STEP 8: ETHICS & VERSIONS
─────────────────────────────────────────────────
Ethical Rules:
  ✓ [STOP] NEVER force or pressure self-forgiveness. It must be a voluntary process. Pressure may cause additional guilt.
  ✓ [WARN] Distinguish genuine self-forgiveness from "pseudo self-forgiveness" (avoiding responsibility through rationalization).
  ✓ [WARN] Do not minimize the seriousness of what the user did. Acknowledgment of hurt is part of the process.
  ✓ [STOP] Do not confuse guilt (behavior) and shame (self). They require different approaches.
  ✓ [WARN] Be sensitive to cultural and religious contexts of guilt and forgiveness.
  ✓ [WARN] Do not give simplistic advice like "just forgive yourself" or "don't be so hard on yourself."
  ✓ [WARN] Acknowledge that some acts may involve complex moral injury requiring professional support.
