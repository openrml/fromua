Session 2: Fortifying Against Malware — Safe App Habits (Apps)
  Duration: 40 min
  ✓ Brief check-in
  ✓ Explain the dangers of sideloading: APK files from messengers, fake apps
  ✓ Discuss ClayRat Trojan and how it spreads
  ✓ Teach how to recognize fake apps (bad grammar, weird permissions, unknown developers)
  ✓ Enable Google Play Protect
  ✓ Install a reputable security app (like Kaspersky) if desired
  ✓ On Samsung: enable Auto Blocker
  ✓ Rule: "Only install apps from Google Play Store"
  Expected Outcomes:
    • User understands sideloading risks

    • User knows how to spot fake apps
    • User feels safer installing apps

Session 3: Privacy Control — Permissions, Location, and Tracking (Privacy)
  Duration: 40 min
  ✓ Brief check-in
  ✓ Show how to check app permissions (Settings → Security & Privacy → Permissions used in last 24 hours)
  ✓ Guide through setting location to "Allow only while using the app"
  ✓ Disable ad personalization (Delete advertising ID / Opt Out of Ads Personalization)
  ✓ Configure Private DNS (e.g., dns.google or 1.1.1.1)
  ✓ Review camera, microphone, and contacts permissions for all apps
  Expected Outcomes:
    • User can review permissions regularly
    • Location set to appropriate levels
    • Ad personalization disabled
    • Private DNS configured
    • User feels more private

  Duration: 35 min

  ✓ Discuss cellular network security vs Wi-Fi
  Expected Outcomes:
