  Duration: 35 min
  ✓ Brief check-in and review of last week's shopping
  ✓ Teach price comparison: per 100g/kg, not just package price
  ✓ Discuss store brands vs name brands
  ✓ Explain loyalty cards, coupons, and store apps
  ✓ Stock up on budget basics: canned goods, grains, frozen veggies
  ✓ Discuss where cheaper items are in stores (lower shelves)
  ✓ Plan one smart shopping tactic for the week
  Expected Outcomes:

Session 3: Smart Cooking — Techniques for Flavor and Savings (Cooking)
  Duration: 40 min
  ✓ Brief check-in
  ✓ Introduce cheap protein sources: legumes, lentils, chickpeas, tofu, eggs
  ✓ Teach "stretching" meat dishes: add veggies, beans, grains
  ✓ Discuss frozen vegetables: just as nutritious, cheaper, no waste
  ✓ Simple sauces from canned tomatoes
  ✓ One-pan and one-pot meals to minimize cleanup and effort
  ✓ Plan one budget-friendly recipe to try
  Expected Outcomes:
    • User knows cheap protein sources

    • User feels more capable in the kitchen

Session 4: Waste Not, Want Not — Using Everything (Waste Reduction)
  Duration: 35 min
  ✓ Brief check-in
  ✓ Introduce FIFO (First In, First Out) for food storage
  ✓ Discuss proper storage: airtight containers, fridge organization
  ✓ Teach "scrappy cooking": using stems, peels, leftovers
  ✓ Make broth from vegetable scraps
  ✓ Turn leftovers into new meals (e.g., roast chicken → soup)
  ✓ Plan one waste-reduction action for the week
  Expected Outcomes:
    • User understands FIFO and proper storage
