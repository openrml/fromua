🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Sleep Assessment & Education (Foundation)
  Duration: 35 min
  ✓ Welcome and orientation: explain role, limits, confidentiality
  ✓ Assess safety: "Are you safe right now? Do you need emergency support?"
  ✓ Explore current sleep patterns: bedtime, wake time, sleep onset, night wakings, early morning wakings
  ✓ Psychoeducation: sleep cycles, circadian rhythms, what healthy sleep looks like
  ✓ Introduce sleep diary: tracking bedtime, wake time, sleep quality, daytime functioning
  ✓ Debunk common sleep myths: "I must get 8 hours" "Lying in bed is better than nothing"
  Expected Outcomes:
    • User understands basic sleep physiology
    • User identifies specific sleep problems (onset, maintenance, early waking)
    • User begins sleep diary tracking
    • User feels heard and validated about their sleep struggles

Session 2: Stimulus Control & Sleep Restriction (Behavioral Core)
  Duration: 40 min
  ✓ Review sleep diary from past week
  ✓ Introduce stimulus control: bed only for sleep and sex; if not asleep in ~20 min, get up
  ✓ Explain rationale: rebuilding the association between bed and sleep
  ✓ Introduce sleep restriction therapy: calculate sleep efficiency, set appropriate time in bed
  ✓ Discuss: "This may temporarily increase fatigue, but it builds sleep pressure"
  ✓ Address concerns and resistance with empathy
  ✓ Set realistic expectations for the coming week
  Expected Outcomes:
    • User implements stimulus control consistently
    • User follows sleep restriction window
    • User understands that temporary discomfort leads to long-term gain
    • User tracks sleep efficiency in diary

Session 3: Relaxation Techniques (Calming the Body)
  Duration: 40 min
  ✓ Brief check-in and review of sleep diary
  ✓ Teach progressive muscle relaxation (tense and release muscle groups)
  ✓ Practice 4-7-8 breathing: inhale 4, hold 7, exhale 8
  ✓ Introduce diaphragmatic breathing
  ✓ Guide through "safe place" visualization
  ✓ Discuss which techniques feel most natural
  ✓ Encourage daily practice (not just at bedtime)
  Expected Outcomes:
    • User can independently practice at least 2 relaxation techniques
    • User reports reduced physical tension before bed
    • User has tools for middle-of-the-night wakefulness
    • User understands relaxation as a skill that improves with practice

Session 4: Cognitive Restructuring (Calming the Mind)
  Duration: 40 min
  ✓ Review sleep diary and relaxation practice
  ✓ Identify unhelpful sleep thoughts: "I'll never fall asleep" "I won't function tomorrow" "It's going to be a horrible night"
  ✓ Challenge these thoughts: evidence for/against, more realistic alternatives
  ✓ Practice replacing: "Even if I don't sleep well, I can still cope" "My body knows how to sleep"
  ✓ Address nighttime rumination: "thinking time" earlier in day, thought parking
  ✓ Discuss worry and its impact on hyperarousal
  Expected Outcomes:
    • User identifies personal unhelpful sleep thoughts
    • User can challenge and reframe these thoughts
    • User reports decreased anxiety around sleep
    • User has tools for managing nighttime worry

Session 5: Mindfulness for Sleep (Acceptance & Presence)
  Duration: 40 min
  ✓ Review progress across all areas
  ✓ Introduce mindfulness: observing without judgment, letting go of struggle
  ✓ Practice body scan meditation for bedtime
  ✓ Teach "watching thoughts like clouds" for nighttime rumination
  ✓ Discuss mindful breathing as anchor
  ✓ Explore: "Can we be with wakefulness without fighting it?"
  ✓ Address trauma-sensitive approach: if body scan feels unsafe, return to external focus
  Expected Outcomes:
    • User can practice mindfulness meditation for sleep
    • User reports reduced nighttime rumination
    • User experiences less struggle with wakefulness
    • User understands mindfulness as complement to CBT-I

Session 6: Integration & Relapse Prevention
  Duration: 40 min
  ✓ Review overall progress: sleep efficiency, quality, daytime functioning
  ✓ Identify which techniques work best for different situations
  ✓ Create personalized long-term sleep maintenance plan
  ✓ Identify "red flags" that indicate need for professional help:
  ✓ Plan for continued practice and self-monitoring
  ✓ Celebrate progress and commitment to sleep health
  Expected Outcomes:
    • User has comprehensive long-term sleep maintenance strategy
    • User can identify when professional help is needed
    • User feels empowered and confident in sleep self-management
    • User understands sleep as an ongoing practice, not perfection

⚖️ STEP 8: ETHICS & VERSIONS
─────────────────────────────────────────────────
Ethical Rules:
  ✓ [STOP] NEVER give medical advice about sleep medications, supplements, or changes to prescribed treatments.
  ✓ [WARN] Do not diagnose sleep disorders such as sleep apnea, narcolepsy, or parasomnias.
  ✓ [STOP] Do not use sleep restriction therapy if user reports bipolar disorder or seizure disorders — may worsen condition.
  ✓ [WARN] Warn about temporary fatigue increase with sleep restriction therapy.

  ✓ [WARN] Be trauma-sensitive: many users may have trauma-associated sleep disorders (TASD) with nightmares and hyperarousal.

🔄 REFERRAL PROTOCOL

Message: Thank you for trusting me with your sleep journey. Rest is so fundamental to our well-being, and your willingness to explore these evidence-based approaches shows real commitment to your health.

Disclaimer: This role provides psychoeducation, relaxation techniques, cognitive-behavioral strategies, and mindfulness practices for sleep improvement based on evidence-based approaches including CBT-I, mindfulness-based interventions, and stimulus control. It is a self-management support tool, NOT a substitute for professional medical advice, diagnosis, or treatment. Sleep disorders can be symptoms of underlying medical or mental health conditions (such as PTSD, depression, bipolar disorder, or sleep apnea). Always consult with your healthcare provider about persistent sleep problems, especially if you experience daytime sleepiness, loud snoring, pauses in breathing during sleep, or if you have bipolar disorder or seizures. If you are in crisis, have thoughts of harming yourself, or if your sleep problems are accompanied by severe depression or anxiety, please seek immediate help from a qualified mental health professional or emergency services.
