Session 1: Understanding Burnout and Compassion Fatigue (Awareness)
  Duration: 35 min
  ✓ Welcome and orientation: explain role, limits, confidentiality
  ✓ Assess safety: "Are you safe right now? Do you need emergency support?"
  ✓ Psychoeducation: three dimensions of burnout (exhaustion, cynicism, reduced accomplishment)
  ✓ Introduce compassion fatigue as professional risk for helpers
  ✓ Normalize: "This is not a personal failure — it's an occupational hazard"
  ✓ Assess own state: where do you notice signs of burnout?
  ✓ Introduce concept of "recovery time" as essential
  Expected Outcomes:
    • User understands burnout as systemic, not personal
    • User can identify own burnout symptoms
    • User feels validated and less alone
    • User understands importance of recovery

Session 2: The Foundation of Self-Care (Recovery Time)
  Duration: 40 min
  ✓ Brief check-in and grounding
  ✓ Explore concept of "recovery time": chronic stress without recovery has serious consequences
  ✓ Identify barriers to rest: guilt, perfectionism, "others need me"
  ✓ Challenge belief: "Taking care of myself allows me to care for others sustainably"
  ✓ Plan micro-breaks throughout the day (2-5 minutes)
  ✓ Introduce quick recovery techniques: breathing, stretching, stepping outside
  ✓ Create daily recovery plan
  Expected Outcomes:
    • User recognizes critical importance of rest
    • User experiences reduced guilt about pauses
    • User implements micro-breaks in daily routine
    • User feels more in control of energy

Session 3: Mindfulness and Self-Regulation (Calming the Nervous System)
  Duration: 40 min
  ✓ Brief check-in and review of recovery practice
  ✓ Introduce mindfulness: paying attention to present moment without judgment
  ✓ Practice mindful breathing (3-5 minutes)
  ✓ Guide through body scan for tension release
  ✓ Introduce grounding for acute stress: 5-4-3-2-1 (external focus)
  ✓ Discuss: "Mindfulness helps us respond, not react"
  ✓ Encourage daily short practices
  Expected Outcomes:
    • User can practice basic mindfulness techniques
    • User reports reduced physiological arousal
    • User has tools for acute stress moments
    • User understands mindfulness as skill to develop

Session 4: Building Emotional Resilience (Positive Psychology)
  Duration: 40 min
  ✓ Brief grounding and check-in
  ✓ Introduce concept of resilience: adapting to stress through coping and support
  ✓ Explore optimism as protective factor: not blind positivity, but realistic hope
  ✓ Practice gratitude: three good things from work today
  ✓ Identify personal strengths and how they help in work
  ✓ Discuss meaning in work: "What called you to this work originally?"
  ✓ Connect to values that sustain through difficulty
  Expected Outcomes:
    • User identifies personal strengths and sources of meaning
    • User practices gratitude and optimism skills
    • User experiences increased sense of purpose
    • User feels more resilient

Session 5: The Power of Connection (Support Systems)
  Duration: 40 min
  ✓ Brief grounding and check-in
  ✓ Discuss: "We are not meant to carry this alone"
  ✓ Map support network: colleagues, friends, family, mentors, professional support
  ✓ Explore barriers to asking for help (shame, self-reliance, "helpers don't need help")
  ✓ Normalize peer support and debriefing after difficult cases
  ✓ Practice reaching out: who can you connect with this week?
  ✓ Discuss importance of "ambassadors of positive emotion" in workplace culture
  Expected Outcomes:
