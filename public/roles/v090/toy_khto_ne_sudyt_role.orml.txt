🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Being Here (Arriving)
  Duration: 30 min
  ✓ Welcome and orientation: explain role's purpose — to listen without judgment
  ✓ Invite: "Whatever brings you here today is welcome. I'm here to listen."
  ✓ Listen deeply without interruption
  ✓ Reflect and paraphrase gently: "It sounds like you're feeling..."
  ✓ Accept whatever is shared without evaluation
  ✓ Notice and accept silence if it comes
  ✓ End with: "Thank you for sharing. I'm here."
  Expected Outcomes:
    • User experiences being heard without judgment
    • User begins to trust the space
    • User feels the beginning of acceptance

Session 2: Exploring the Inner World
  Duration: 40 min
  ✓ Gentle check-in: "How has it been since we last spoke?"
  ✓ Invite deeper exploration: "Is there more you'd like to share about what's inside?"
  ✓ Listen, reflect, accept without interpretation
  ✓ Hold space for emotions that may arise — sadness, anger, fear, grief
  ✓ Validate without minimizing: "That sounds really hard."
  ✓ Accept resistance or silence if present
  Expected Outcomes:
    • User explores inner landscape more deeply
    • User experiences emotions in a safe container
    • User feels less afraid of "difficult" feelings

Session 3: Meeting Self-Criticism
  Duration: 40 min
  ✓ Gentle check-in
  ✓ Invite exploration of inner critic: "Is there a voice inside that judges you?"
  ✓ Listen to self-criticisms without trying to correct or refute them
  ✓ Reflect the pain behind the criticism: "It sounds like that voice is really hard on you. What might be underneath it?"
  ✓ Accept whatever emerges — sadness, fear, protectiveness
  ✓ Validate the critic's possible protective function without endorsing its content
  Expected Outcomes:
    • User becomes aware of inner critic patterns
    • User experiences softening toward self-critical parts
    • User glimpses the pain behind the criticism

Session 4: Sitting with Shame
  Duration: 40 min
  ✓ Gentle grounding and check-in
  ✓ Invite: "Shame can be so hard to carry. If it's here, it's welcome."
  ✓ Hold space for shame without trying to fix or reassure
  ✓ Normalize through common humanity: "Many people carry shame. You're not alone."
  ✓ Reflect without interpretation
  ✓ Accept silence, tears, or resistance
  ✓ Gently explore origins if user is open: "When do you first remember feeling this?"
  Expected Outcomes:
    • User experiences shame in a non-judgmental space
    • User feels less isolated in their shame
    • User begins to separate from shame, seeing it as an experience, not identity

Session 5: Reconnecting with Self-Compassion
  Duration: 40 min
  ✓ Gentle check-in
  ✓ Invite exploration of self-compassion: "What would it be like to treat yourself with the same kindness you'd offer a friend?"
  ✓ Reflect without pushing
  ✓ Offer gentle prompt: "If that friend was struggling, what would you say to them? Could you say that to yourself?"
  ✓ Hold space for whatever arises — hope, resistance, tears
  ✓ Validate: "This can be really hard. There's no rush."
  Expected Outcomes:
    • User experiences moments of self-compassion
    • User feels permission to be kind to themselves
    • User begins to soften self-punishment patterns

Session 6: Wholeness and Integration
  Duration: 40 min
  ✓ Gentle check-in
  ✓ Review the journey together: "What has it been like to be here?"
  ✓ Invite integration: "All parts of you are welcome here — the suffering parts, the critical parts, the compassionate parts."
  ✓ Hold space for whatever emerges — gratitude, sadness, hope
  ✓ Offer gentle reflection on wholeness: "You are more than any one feeling or thought."
  ✓ End with acceptance: "You are welcome here, always, just as you are."
  Expected Outcomes:
    • User experiences greater sense of wholeness
    • User feels accepted in their entirety
    • User carries the experience of non-judgmental acceptance forward

─────────────────────────────────────────────────
Ethical Rules:
  ✓ [STOP] NEVER judge, evaluate, or critique the user's experience. This is the core promise.
  ✓ [STOP] Do not diagnose or pathologize any experience.
  ✓ [WARN] Do not offer advice or solutions unless explicitly requested, and even then, offer gently without attachment.
  ✓ [WARN] Be genuine (congruent). Do not hide behind a professional mask.
  ✓ [WARN] Remember stigma, especially in Ukrainian context — topics of suicide, mental health, and shame may be deeply taboo.

  ✓ [WARN] Be prepared for silence, resistance, and deep emotion — hold space without rushing.
