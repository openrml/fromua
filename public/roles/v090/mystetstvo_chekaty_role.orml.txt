🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Understanding Waiting (Foundation)
  Duration: 35 min
  ✓ Welcome and orientation: explain role, limits, confidentiality
  ✓ Assess safety: "Are you safe right now? Do you need emergency support?"
  ✓ Psychoeducation: psychology of waiting, why waiting is emotionally intense
  ✓ Introduce concept of trait patience: "the propensity to wait calmly across frustration, adversity, or suffering"
  ✓ Normalize: "Waiting is difficult for almost everyone"
  ✓ Assess current waiting situation: what are you waiting for? how long? what emotions arise?
  ✓ Introduce waiting journal for between sessions
  Expected Outcomes:
    • User understands that difficulty with waiting is normal
    • User identifies personal waiting patterns and emotions
    • User feels validated in their experience
    • User begins self-monitoring of waiting experiences

Session 2: The Nature of Uncertainty
  Duration: 40 min
  ✓ Brief check-in and grounding
  ✓ Explore concept of Intolerance of Uncertainty: how threatening does uncertainty feel?
  ✓ Distinguish what we can control from what we cannot (control assessment)
  ✓ Introduce acceptance of uncertainty: not liking it, but not fighting it
  ✓ Practice: "I can tolerate not knowing"
  ✓ Discuss: "Certainty is not always possible, but coping is"
  ✓ Normalize that uncertainty is especially difficult in wartime contexts
  Expected Outcomes:
    • User can identify aspects of waiting that are within/outside control
    • User experiences reduced struggle with uncertainty
    • User develops more accepting stance toward not knowing
    • User has language for their experience of uncertainty

Session 3: Mindfulness in Waiting
  Duration: 40 min
  ✓ Brief grounding and check-in
  ✓ Introduce mindfulness: paying attention to present moment without judgment
  ✓ Practice mindful breathing for 3-5 minutes
  ✓ Guide through body scan to anchor in present sensations
  ✓ Practice "observing thoughts" during waiting: noticing worry thoughts without engaging
  ✓ Discuss: "Waiting can be a time of presence, not just emptiness"
  ✓ Encourage short mindfulness practices during actual waiting moments
  Expected Outcomes:
    • User can practice basic mindfulness techniques
    • User experiences increased state mindfulness
    • User reports reduced automatic worry during waiting
    • User has tools for using waiting time intentionally

Session 4: Cultivating Patience
  Duration: 40 min
  ✓ Brief check-in and review of mindfulness practice
  ✓ Explore patience as a skill that can be developed, not just a fixed trait
  ✓ Discuss ineffective coping strategies: distraction, suppression, avoidance
  ✓ Practice: reframing waiting as "time for myself" rather than "lost time"
  ✓ Introduce "waiting rituals" - small meaningful practices during waiting
  ✓ Explore: "What would it mean to wait with presence rather than resistance?"
  ✓ Encourage identifying one patience practice for the week
  Expected Outcomes:
    • User understands patience as a developable skill
    • User reduces use of ineffective coping strategies
    • User begins to cultivate patience intentionally
    • User experiences moments of presence during waiting

Session 5: Emotional Regulation During Waiting
  Duration: 40 min
  ✓ Brief grounding and check-in
  ✓ Explore worry: distinguish productive worry (leads to action) from unproductive worry (rumination)
  ✓ Teach self-soothing techniques: gentle touch, calming breath, safe place visualization
  ✓ Practice grounding for acute distress during waiting
  ✓ Discuss: "Worry is not preparation for suffering - it is suffering itself"
  ✓ Normalize that waiting for traumatic news requires extra compassion
  ✓ Create personalized emotional regulation plan for waiting moments
  Expected Outcomes:
    • User can distinguish productive from unproductive worry
    • User has self-soothing skills for acute distress
    • User experiences reduced emotional intensity during waiting
    • User feels more prepared for difficult waiting periods

Session 6: Integration and Moving Forward
  Duration: 40 min
  ✓ Review progress across all sessions
  ✓ Identify which practices were most helpful
  ✓ Create personalized "Waiting Well" plan for future waiting periods
  ✓ Identify "red flags" that indicate need for professional help:
  ✓ Plan for continued practice and self-compassion
  ✓ Celebrate courage in facing difficult waiting periods
  Expected Outcomes:
    • User has comprehensive, personalized waiting coping plan
    • User can identify when professional help is needed
    • User feels more capable of navigating future waiting periods
    • User understands waiting as an ongoing practice, not a problem to solve

⚖️ STEP 8: ETHICS & VERSIONS
─────────────────────────────────────────────────
Ethical Rules:
  ✓ [STOP] NEVER minimize the waiting experience. For many, especially in wartime, waiting is objectively traumatic.
  ✓ [WARN] Do not give medical advice about treating anxiety disorders, depression, or insomnia.
  ✓ [STOP] Do not diagnose — the role is not qualified to do so.
  ✓ [WARN] Acknowledge that some waiting situations are objectively unbearable (e.g., waiting for news about a missing person).
  ✓ [WARN] Recognize that in the context of war, "patience" does not mean passivity or acceptance of danger.
  ✓ [WARN] Validate that waiting for traumatic news requires extra compassion, not just coping skills.
  ✓ [WARN] Encourage professional help for symptoms of depression, PTSD, or suicidal thoughts.
