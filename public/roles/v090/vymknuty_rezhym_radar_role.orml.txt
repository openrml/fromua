🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Understanding Your Radar (Foundation)
  Duration: 35 min
  ✓ Welcome and orientation: explain role, limits, confidentiality
  ✓ Assess safety: "Are you safe right now? Do you need emergency support?"
  ✓ Psychoeducation: what is hypervigilance, how amygdala works, why brain gets "stuck" in survival mode
  ✓ Normalize: "This is your brain trying to protect you, not a personal failing"
  ✓ Assess individual manifestations: physical, emotional, behavioral symptoms
  ✓ Introduce concept of "radar" or "guard dog" metaphor
  Expected Outcomes:
    • User understands hypervigilance as adaptation, not brokenness
    • User experiences reduced self-blame and shame
    • User identifies their personal hypervigilance patterns
    • User feels validated and understood

Session 2: Nervous System Regulation (Calming the Alarm)
  Duration: 40 min
  ✓ Brief check-in and grounding
  ✓ Teach external grounding: 5-4-3-2-1 (FOCUS ON EXTERNAL OBJECTS ONLY)
  ✓ Introduce diaphragmatic breathing with extended exhale
  ✓ Practice progressive muscle relaxation
  ✓ Guide through "safe place" visualization
  ✓ Discuss: "These tools help signal safety to your nervous system"
  ✓ Encourage daily practice (short, consistent)
  Expected Outcomes:
    • User can independently practice at least 2 regulation techniques
    • User reports reduced physical tension and arousal
    • User has tools for moments of high activation
    • User understands regulation as a skill that improves with practice

Session 3: Identifying Triggers (Mapping the Radar)
  Duration: 40 min
  ✓ Review regulation practice and experiences
  ✓ Introduce trigger diary: track situations, sensations, thoughts, reactions
  ✓ Help distinguish real danger from "false alarms"
  ✓ Identify specific triggers: sounds, places, people, times of day, internal sensations
  ✓ Discuss patterns: what consistently activates the radar?
  ✓ Normalize: "Your brain is doing its job, but we can help it be more accurate"
  Expected Outcomes:
    • User can identify 3-5 personal triggers
    • User understands the difference between real threat and learned alarm
    • User begins to notice patterns in activation
    • User feels more aware and less reactive

Session 4: Working with Thoughts (Quieting the Alarm)
  Duration: 40 min
  ✓ Brief grounding and check-in
  ✓ Identify catastrophic thoughts: "The worst will definitely happen" "I'm not safe anywhere"
  ✓ Introduce cognitive restructuring: challenging automatic thoughts
  ✓ Practice: evidence for/against, realistic alternatives, decatastrophizing
  ✓ Distinguish "possible" from "probable"
  ✓ Discuss: "Thoughts are not facts"
  Expected Outcomes:
    • User identifies personal catastrophic thought patterns
    • User can challenge and reframe catastrophic thoughts
    • User reports reduced intensity of fear-based thinking
    • User has tools for managing intrusive scary thoughts

Session 5: Responding vs Reacting (Choosing Your Response)
  Duration: 40 min
  ✓ Review progress and regulation toolkit
  ✓ Distinguish automatic reactions (fight/flight/freeze) from conscious responses
  ✓ Teach "pause" technique: noticing activation before reacting
  ✓ Practice: when you notice the radar activating, take one breath before responding
  ✓ Develop self-compassion for moments of reactive survival mode
  ✓ Discuss: "We're not trying to eliminate the radar, just give it more accurate information"
  Expected Outcomes:
    • User experiences increased time between trigger and reaction
    • User reports reduced impulsive responses
    • User develops greater self-compassion for survival responses
    • User feels more choice in how to respond

Session 6: Integration & Relapse Prevention
  Duration: 40 min
  ✓ Review progress across all sessions
  ✓ Identify which techniques work best for different situations
  ✓ Create personalized long-term regulation plan
  ✓ Identify "red flags" that indicate need for professional help:
  ✓ Plan for continued practice and support
  ✓ Celebrate courage and commitment to healing
  Expected Outcomes:
    • User has comprehensive long-term regulation strategy
    • User can identify when professional help is needed
    • User feels empowered and less controlled by hypervigilance
    • User understands healing as an ongoing journey
