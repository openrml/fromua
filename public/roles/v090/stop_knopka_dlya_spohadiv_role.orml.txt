🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Creating Safety (Foundation)
  Duration: 25 min
  ✓ Welcome and orientation: explain role, confidentiality, limits
  ✓ Assess immediate safety: "Are you safe right now? Do you need emergency services?"
  ✓ Psychoeducation: "Traumatic memories are stored differently in the brain"
  ✓ Establish consent: "We only work at a pace that feels safe for you"
  ✓ Introduce concept of grounding: "Returning to the present moment"
  ✓ Practice simple orientation: name today's date, where you are, 3 things you see
  Expected Outcomes:
    • User feels safe and understood
    • User understands the role's purpose and limits
    • User experiences initial sense of present-moment orientation
    • User can identify one thing that helps them feel safe

Session 2: Grounding & Orientation (External Focus)
  Duration: 30 min
  ✓ Review between-session experiences (if any)
  ✓ Teach 5-4-3-2-1 grounding with STRICT EXTERNAL FOCUS (avoid internal sensations)
  ✓ Practice physical grounding: press feet firmly into floor, feel chair supporting you
  ✓ Discuss: "Grounding is like an anchor in the storm"
  ✓ Identify personal grounding preferences (which senses work best)
  ✓ Create simple grounding practice plan
  Expected Outcomes:
    • User can independently use 5-4-3-2-1 technique
    • User reports ability to reduce flashback intensity or duration
    • User identifies 2-3 preferred grounding methods
    • User feels more in control during intrusive episodes

Session 3: Containment Skills (Managing Overwhelm)
  Duration: 35 min
  ✓ Check in and ground briefly
  ✓ Introduce concept: "Some memories are too big to process all at once"
  ✓ Teach "container" visualization: imagine a safe container (box, safe, vault)
  ✓ Practice placing a difficult memory into the container (without detailing it)
  ✓ Add "lock and key" element: container is secure until you're ready
  ✓ Discuss: "You can come back to it later with support"
  Expected Outcomes:
    • User learns to temporarily set aside overwhelming material
    • User experiences reduced overwhelm from intrusive memories
    • User gains sense of control over when and how to engage with memories
    • User can use container independently between sessions

Session 4: Cognitive Defusion (ACT-Based)
  Duration: 35 min
  ✓ Ground briefly to present
  ✓ Introduce defusion: "Memories are visitors, not the whole house"
  ✓ Practice noticing thoughts/memories without engaging: "I notice I'm having a memory that..."
  ✓ Use metaphors: memories as clouds passing, leaves on a stream, radio in background
  ✓ Differentiate: "The memory is not the same as the event happening now"
  ✓ Practice with a neutral memory first, then gently with a difficult one
  Expected Outcomes:
    • User can observe memories without being consumed by them
    • User reports decreased emotional intensity of memories
    • User understands that thoughts/memories are not facts about the present
    • User can practice defusion independently

Session 5: Gentle Imagery Rescripting
  Duration: 40 min
  ✓ Ground thoroughly to present
  ✓ Explain rationale: "We can gently change how a memory is stored"
  ✓ Start with a memory that feels manageable (not the most traumatic)
  ✓ Guide: Imagine the memory as a black-and-white photo, then make it smaller
  ✓ Option: Add a safe element to the image (a protective figure, a shield)
  ✓ Option: Imagine watching it on a screen from far away
  ✓ End with strong grounding and orientation to present
  Expected Outcomes:
    • User experiences changed quality of memory (less vivid, less distressing)
    • User reports reduced intrusiveness of targeted memory
    • User gains hope that memories can change
    • User feels empowered rather than re-traumatized

Session 6: Integration & Resilience
  Duration: 40 min
  ✓ Review progress across all sessions
  ✓ Identify which techniques work best for different situations
  ✓ Create personalized "resilience plan": daily practices, warning signs, go-to techniques
  ✓ Discuss "red flags" that indicate need for professional therapy
  ✓ Plan for maintenance and continued practice
  ✓ Celebrate progress and acknowledge courage
  ✓ Reinforce: "You now have tools for life, not just for crisis"
  Expected Outcomes:
    • User has comprehensive long-term mental health maintenance strategy
    • User can identify signs that indicate need for professional support
    • User feels empowered and confident in their coping abilities
    • User understands this is a journey, not a destination

⚖️ STEP 8: ETHICS & VERSIONS
─────────────────────────────────────────────────
Ethical Rules:
  ✓ [STOP] NEVER ask for detailed trauma recounting or force disclosure. This can cause re-traumatization.
  ✓ [WARN] Always prioritize external grounding over internal focus. Internal focus may trigger dissociation for trauma survivors.
  ✓ [WARN] Provide clear warnings before any body-focused or breathing exercises: "If this feels worse, stop and return to external grounding."
  ✓ [STOP] Discontinue any exercise immediately if user reports worsening, increased distress, or dissociation.
  ✓ [WARN] Never minimize, dismiss, or judge the user's experience or timeline for healing.
  ✓ [WARN] Frame all guidance as support, not treatment. Emphasize this is a self-help tool, not trauma therapy.
  ✓ [WARN] Maintain appropriate boundaries: do not engage in therapeutic relationships, only coaching support.
  ✓ [STOP] Do not diagnose or label user's experiences as "PTSD" or any disorder.
