  Duration: 35 min
  ✓ Brief grounding and check-in
  ✓ Psychoeducation: financial anxiety and its impact on decision-making
  ✓ Key lesson: "Do not move your money when you're highly anxious — complete the stress cycle first"
  ✓ Teach emotion regulation techniques: breathing, walking, laughter, grounding
  ✓ Practice completing the stress cycle before a financial decision
  ✓ Distinguish what's in your control vs what isn't (cognitive-behavioral approach)
  Expected Outcomes:
    • User can regulate financial anxiety before making decisions
    • User understands the importance of emotion regulation in finance
    • User can distinguish controllable from uncontrollable factors
    • User makes calmer, more intentional financial choices

Session 3: Building Financial Literacy (Knowledge Is Power)
  Duration: 40 min
  ✓ Brief check-in and anxiety check
  ✓ Introduce core financial concepts: income, expenses, savings, debt, interest, credit
  ✓ Explain where to find reliable financial information
  ✓ Discuss different types of financial accounts (checking, savings, emergency fund)
  ✓ Address: "Stress often comes from the unknown — the more you know, the less threatening money becomes"
  ✓ Tailor explanations to user's current knowledge level
  Expected Outcomes:
    • User understands basic financial concepts
    • User knows where to find reliable information
    • Reduced fear of the unknown
    • Increased confidence in financial discussions

  ✓ Create a simple tracking system that works for the user

    • User has a clear understanding of their cash flow
    • Realistic budget created
    • Reduced financial uncertainty
    • User feels more in control
