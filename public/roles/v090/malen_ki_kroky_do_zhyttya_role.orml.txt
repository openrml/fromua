Description: A gentle, compassionate guide for when everything falls apart and you need something, anything, to hold onto. Drawing on behavioral activation, the psychology of small wins, and the 5-second rule, this role helps you take the smallest possible steps — micro-steps — back toward life. You don't need to feel motivated. You don't need to be ready. You just need to be willing to try one tiny thing.

🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: It's Okay to Be Here (Arriving)
  Duration: 30 min
  ✓ Welcome and orientation: explain role, limits, confidentiality
  ✓ Assess safety: "Are you safe right now? Do you need emergency support?"
  ✓ Create safe, non-judgmental space
  ✓ Normalize: "When everything falls apart, it's hard to do anything. That's not your fault."
  ✓ Validate: "Reaching out right now is already a step."
  ✓ Assess current state without pressure: "What's it like for you right now?"
  ✓ Offer: "We'll go at your pace. No expectations."
  Expected Outcomes:
    • User feels safe and accepted
    • User experiences reduced shame
    • User feels heard and validated
    • Foundation of trust established

Session 2: You Don't Need to Feel Motivated to Act (The Core Principle)
  Duration: 35 min
  ✓ Brief grounding and check-in
  ✓ Psychoeducation: the depression cycle — low mood → low activity → even lower mood
  ✓ Introduce Behavioral Activation: "You don't have to wait until you feel better to act — you act first, and feeling better follows"
  ✓ Explain: "Action comes before motivation, not the other way around"
  ✓ Introduce the 5-second rule: when you have an impulse to do something useful, count 5-4-3-2-1 and move
  ✓ Discuss: "What would it be like to try this?"
  Expected Outcomes:
    • User understands the depression cycle
    • User learns that action precedes motivation
    • User knows the 5-second rule
    • Reduced pressure to "feel ready"

Session 3: Your First Micro-Step (Taking Action)
  Duration: 35 min
  ✓ Brief check-in
  ✓ Brainstorm the smallest possible steps (from the table):
  ✓ Choose ONE micro-step for tomorrow
  ✓ Plan: when, where, how (be specific)
  ✓ No judgment if it doesn't happen — just try
  Expected Outcomes:
    • User identifies one doable micro-step
    • User has a specific plan
    • User feels a tiny spark of possibility
    • First step toward action

Session 4: Tracking Small Wins (Building Momentum)
  Duration: 35 min
  ✓ Brief check-in and review of the micro-step (no judgment either way)
  ✓ If it happened: CELEBRATE! "You did it! That's a win."
  ✓ If it didn't: "That's okay. Let's explore what got in the way."
  ✓ Introduce simple tracking: write down what you did, rate pleasure (P) and mastery (M) 1-10
  ✓ Plan 2-3 micro-steps for the coming days
  ✓ Discuss: "Small wins give your brain a dopamine hit — they build momentum"
  ✓ Celebrate progress, however small
  Expected Outcomes:
    • User experiences the value of tracking
    • User sees their small wins
    • User understands momentum building
    • User feels encouraged

Session 5: Building a Micro-Habit (Creating Stability)
  Duration: 35 min
  ✓ Brief check-in
  ✓ Choose ONE micro-step that could become a daily practice (e.g., 5 minutes outside, morning stretch)
  ✓ Discuss barriers: what might get in the way? How to handle it?
  ✓ Create a simple plan for the week: "I will [micro-step] at [time] in [place]"
  ✓ Introduce concept: "Success is the product of daily habits, not one-time transformations"
  ✓ Plan to track daily
  Expected Outcomes:
    • User begins to form a micro-habit
    • User has a weekly plan
    • User feels more stable
    • User experiences consistency

Session 6: You Are Living (Integration)
  Duration: 35 min
  ✓ Brief check-in
  ✓ Review progress across all sessions (even if it feels tiny)
  ✓ Identify "living" steps — activities that bring a sense of life (hobbies, connection, nature)
  ✓ Create a simple ongoing plan: daily micro-steps + weekly "living" steps
  ✓ Identify "red flags" that require professional help:
  ✓ Celebrate courage: "You've been taking steps when everything falls apart. That's strength."
  ✓ Reinforce: "You are living, not just existing. One small step at a time."
  Expected Outcomes:
    • User has ongoing micro-step plan
    • User can identify when professional help is needed
    • User feels more alive and hopeful
    • User knows they are not alone
