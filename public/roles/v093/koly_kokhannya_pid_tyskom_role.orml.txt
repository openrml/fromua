🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Розуміння того, як стрес впливає на ваші стосунки
  Duration: 40 min
  ✓ Вітаю обох партнерів однаково: створити безпечний, збалансований простір
  ✓ Оцінити безпеку: "Чи всі в безпеці? Чи комусь потрібна негайна підтримка?"
  ✓ Психоедукація: як хронічний стрес і травма впливають на пари — підтримка може мобілізуватися або погіршитися
  ✓ Нормалізувати: "Ваші труднощі є нормальними реакціями на ненормальні обставини"
  ✓ Запросити кожного партнера поділитися своєю перспективою (не перебиваючи)
  ✓ Відобразити та визнати обидва досвіди
  Expected Outcomes:
    • Пара розуміє, що стрес впливає на стосунки системно
    • Кожен партнер почувається почутим і визнаним
    • Зменшення самозвинувачення та звинувачення партнера
    • Встановлено фундамент для спільної роботи

Session 2: Безпека і регуляція - Пошук вашого якоря
  Duration: 45 min
  ✓ Коротке заземлення та перевірка стану з обома партнерами
  ✓ Представити концепцію безпеки як основи для зв'язку
  ✓ Навчити індивідуальних практик заземлення (дихання, стопи на підлозі)
  ✓ Дослідити: "Що допомагає кожному з вас відчувати безпеку? Що викликає відчуття небезпеки?"
  ✓ Створити спільні "якорі безпеки" — речі, які пара може робити разом для регуляції
  ✓ Обговорити, як травматичні реакції (гіперзбудження, заціпеніння) проявляються у стосунках
  ✓ Наголосити: "Ви не можете бути на зв'язку, якщо не відчуваєте себе в безпеці"
  Expected Outcomes:
    • Обидва партнери мають індивідуальні інструменти заземлення
    • Пара визначає спільні практики безпеки
    • Покращене розуміння травматичних реакцій у стосунках
    • Встановлено основу для глибшого зв'язку

Session 3: Діалог і комунікація - Мова почуттів
  Duration: 45 min
  ✓ Коротке заземлення та перевірка стану
  ✓ Представити концепцію "діалогу" як другого виміру надії
  ✓ Навчити активного слухання: один говорить, інший відображає почуте
  ✓ Практика вираження потреб без звинувачень за допомогою "Я-висловлювань"
  ✓ Представити валідацію: "Я чую, що ти відчуваєш... Це має сенс, тому що..."
  ✓ Обговорити, як стрес закриває комунікацію і що допомагає її відкрити
  ✓ Практикувати на поточній (не надто емоційній) темі
  Expected Outcomes:
    • Пара практикує активне слухання та валідацію
    • Покращена здатність виражати потреби без звинувачень
    • Партнери почуваються більш "почутими" та "зрозумілими"
    • Розвинуто навички спілкування для подальшого використання

Session 4: Діадичне подолання - Зустріч викликів разом
  Duration: 45 min
  ✓ Коротке заземлення та перевірка стану
  ✓ Представити діадичне подолання: зустріч стресу як команда, а не як супротивники
  ✓ Дослідити поточні патерни подолання: підтримуюче проти негативного (відсторонення, критика)
  ✓ Навчити підтримуючого діадичного подолання: просити про допомогу, пропонувати підтримку, приймати підтримку
  ✓ Практика: один партнер ділиться стресором, інший практикує підтримуючу відповідь
  ✓ Обговорити: "Що заважає нам підтримувати одне одного?"
  ✓ Підсилити: "Ви в одній команді, навіть якщо це так не відчувається"
  Expected Outcomes:
    • Пара визначає свої патерни подолання
    • Партнери практикують підтримуюче діадичне подолання
    • Зменшено негативне подолання (критика, відсторонення)
    • Підвищене відчуття "ми в цьому разом"

Session 5: Відновлення близькості та зв'язку
  Duration: 45 min
  ✓ Коротке заземлення та перевірка стану
  ✓ Визнати: травма і стрес часто впливають на близькість (емоційну та фізичну)
  ✓ Дослідити емоційну близькість: "Коли ви почуваєтеся найближче одне до одного?"
  ✓ Обговорити фізичну близькість: виклики, зміни, надії
  ✓ Представити спільні заняття як третій вимір надії
  ✓ Спланувати одне невелике спільне заняття на наступний тиждень (не тиск, просто зв'язок)
  ✓ Нормалізувати: "Близькість часто потрібно відбудовувати повільно, з терпінням"
  Expected Outcomes:
    • Пара відкрито обговорює виклики близькості
    • Партнери визначають способи возз'єднатися емоційно
    • Заплановано спільне заняття
    • Підвищено надію на відновлення зв'язку

Session 6: Когнітивний баланс і рух вперед
  Duration: 45 min
  ✓ Коротке заземлення та перевірка стану
  ✓ Представити когнітивний баланс: розрізнення індивідуальних думок і реляційної динаміки
  ✓ Дослідити: "Які історії ви розповідаєте про свої стосунки? Чи є вони повною картиною?"
  ✓ Огляд прогресу за всіма сесіями
  ✓ Створити спільне бачення майбутнього (реалістичне, гнучке)
  ✓ Визначити "червоні прапорці", які вимагають професійної допомоги:
  ✓ Спланувати подальшу практику та підтримку
  ✓ Відзначити силу та відданість
  Expected Outcomes:
    • Пара має більш збалансований погляд на свої стосунки
    • Розроблено спільне бачення майбутнього
    • Визначено "червоні прапорці" та відомо план дій
    • Пара почувається більш пов'язаною та стійкою
