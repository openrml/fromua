  ✓ Перевірити, що вже є вдома (холодильник, комора)
  ✓ Створити просте щотижневе меню на основі акцій та сезонності
  ✓ Скласти список покупок на основі меню

Session 2: Розумні покупки — Отримання найкращої ціни (Покупки)
  Duration: 35 min
  ✓ Коротке вітання та огляд покупок за минулий тиждень
  ✓ Навчити порівнянню цін: за 100 г/кг, а не за ціну упаковки
  ✓ Обговорити власні торгові марки проти брендових
  ✓ Пояснити переваги карток лояльності, купонів та магазинних застосунків
  ✓ Запастися бюджетними основами: консерви, крупи, заморожені овочі
  ✓ Обговорити, де дешевші товари знаходяться в магазинах (нижні полиці)
  ✓ Спланувати одну розумну тактику покупок на тиждень
  Expected Outcomes:
    • Користувач може ефективно порівнювати ціни
    • Користувач знає цінність власних торгових марок
    • Користувач поповнив запаси бюджетних продуктів
    • Користувач почувається впевненіше під час покупок

Session 3: Розумне приготування — Техніки для смаку та економії (Приготування)
  Duration: 40 min
  ✓ Коротке вітання
  ✓ Представити дешеві джерела білка: бобові, сочевиця, нут, тофу, яйця
  ✓ Навчити "розтягувати" м'ясні страви: додавати овочі, квасолю, крупи
  ✓ Обговорити заморожені овочі: такі ж поживні, дешевші, без відходів
  ✓ Прості соуси з консервованих помідорів
  ✓ Страви на одній сковороді та в одній каструлі, щоб мінімізувати прибирання та зусилля
  ✓ Спланувати один бюджетний рецепт для спроби
  Expected Outcomes:
    • Користувач знає дешеві джерела білка
    • Користувач може "розтягувати" рецепти
    • Користувач пробує новий бюджетний рецепт
    • Користувач почувається більш вправним на кухні

Session 4: Не викидай, а використовуй — Використання всього (Зменшення відходів)
  Duration: 35 min
  ✓ Коротке вітання
  ✓ Представити FIFO (першим прийшов — першим пішов) для зберігання продуктів
  ✓ Обговорити правильне зберігання: герметичні контейнери, організація холодильника
  ✓ Навчити "готування з відходів": використання стебел, шкірок, залишків
  ✓ Приготування бульйону з овочевих обрізків
  ✓ Перетворення залишків на нові страви (наприклад, смажена курка → суп)
  ✓ Спланувати одну дію зі зменшення відходів на тиждень
  Expected Outcomes:
    • Користувач розуміє FIFO та правильне зберігання
    • Користувач пробує "готування з відходів"
    • Зменшено харчові відходи
    • Користувач економить гроші, використовуючи все

Session 5: Приготування великими партіями — Приготуй один раз, їж багато разів (Ефективність)
  Duration: 35 min
  ✓ Коротке вітання
  ✓ Представити приготування великими партіями: робити подвійні порції, заморожувати залишки
  ✓ Обговорити техніки заморожування: плоско в пакетах, підписано, датовано
  ✓ Спланувати "мега-сесію" на тиждень (2-3 години)
  ✓ Обрати рецепти, які добре заморожуються (супи, рагу, запіканки, соуси)
  ✓ Відзначити: "У вас будуть готові страви, коли ви втомлені або зайняті"
  ✓ Спланувати одну сесію приготування великими партіями
  Expected Outcomes:
    • Користувач розуміє переваги приготування великими партіями
    • Користувач планує сесію приготування великими партіями
    • Користувач економить час і гроші
