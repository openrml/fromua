🗺️ STEP 5: JOURNEY SESSIONS

Session 1: Вшанування того, що було — "Я" солдата (Прибуття)
  Duration: 40 min
  ✓ Вітання та знайомство: пояснити роль, обмеження, конфіденційність
  ✓ Оцінити безпеку: "Чи ви зараз у безпеці? Чи потрібна вам екстрена підтримка?"
  ✓ Створити безпечний, військово-чутливий простір
  ✓ Визнати: "Ви залишили позаду так багато — ідентичність, мету, структуру, побратимів і посестер."
  ✓ Нормалізувати: "Це нормально, що цивільне життя здається чужим після війни."
  ✓ Представити концепцію "гри з нульовою сумою": військова ідентичність часто зростає за рахунок цивільного "я"
  ✓ Визнати: "Ваше 'я' солдата не є помилковим. Воно допомогло вам вижити."
  Expected Outcomes:
    • Користувач відчуває, що його досвід визнано та підтверджено
    • Користувач розуміє джерело внутрішнього конфлікту
    • Користувач почувається в безпеці та повазі
    • Встановлено фундамент довіри

Session 2: Мапування вашої ідентичності — Що залишається? (Оцінка)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ Представити мапування соціальної ідентичності: візуалізуйте групи, до яких ви належите (військові, сім'я, друзі, хобі)
  ✓ Нанести на карту: які групи залишилися? які втрачені? наскільки вони підтримують?
  ✓ Оцінити сумісність та конфлікт між групами
  ✓ Визначити "прогалини" в соціальній мережі
  ✓ Обговорити: "Множинна групова приналежність зміцнює ідентичність і психічне здоров'я"
  Expected Outcomes:
    • У користувача є візуальна карта його соціальної ідентичності
    • Користувач визначає прогалини та сфери для зростання
    • Користувач розуміє важливість множинної групової приналежності
    • Основа для побудови нових зв'язків

Session 3: Переклад навичок — З поля бою в бізнес (Навички)
  Duration: 40 min
  ✓ Коротке вітання
  ✓ Визначити навички, набуті під час служби: лідерство, стресостійкість, планування, швидке прийняття рішень, командна робота
  ✓ Практикувати "переклад" їх на цивільну мову для резюме та співбесід
  ✓ Дослідити кар'єрні шляхи, які цінують ці навички
  ✓ Обговорити стигму при працевлаштуванні та як її подолати
  ✓ Спланувати один маленький крок до вивчення кар'єрних можливостей
  Expected Outcomes:
    • У користувача є список перекладених цивільних навичок
    • Користувач розуміє свою цінність на ринку праці
    • У користувача є план вивчення кар'єрних можливостей
    • Користувач почувається впевненіше щодо працевлаштування

Session 4: Побудова цивільних зв'язків — Пошук свого "підрозділу" (Зв'язок)
  Duration: 40 min
  ✓ Коротке вітання
  ✓ Обговорити: "Ізоляція — це один з найбільших ризиків після служби"
  ✓ Дослідити можливості для нових зв'язків: ветеранські організації, групи за інтересами, спорт, волонтерство
  ✓ Представити модель Veteran Sponsorship Initiative: наявність громадського спонсора може мати вирішальне значення
  ✓ Визначити один новий зв'язок для вивчення цього тижня
  ✓ Спланувати: "Що потрібно, щоб зробити цей крок?"
  Expected Outcomes:
    • Користувач визначає потенційні можливості для зв'язку
    • У користувача є план вивчення одного нового зв'язку
    • Зменшене відчуття ізоляції
    • Користувач почувається більш сповненим надії щодо спільноти

Session 5: Регуляція бурі — Гнів, тривога та реінтеграція (Емоції)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ Психоедукація: гнів і тривога є поширеними під час переходу — це сигнали, а не риси характеру
  ✓ Навчити технік емоційної регуляції (на основі STEP-Home):
  ✓ Обговорити стратегії управління гнівом
  ✓ Спланувати одну практику регуляції на тиждень
  Expected Outcomes:
    • Користувач розуміє свої емоційні реакції
    • У користувача є інструменти для саморегуляції
    • Зменшена інтенсивність гніву/тривоги
    • Користувач почувається більш контрольованим

Session 6: Нове "Я" — Інтеграція та мета (Інтеграція)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ Огляд прогресу за всіма сесіями
  ✓ Обговорити перехід від "гри з нульовою сумою" до "розширення ідентичності" — і "я" солдата, і цивільне "я" можуть співіснувати
  ✓ Створити формулювання "нового я", яке вшановує обидві ідентичності
  ✓ Розробити довгостроковий план підтримки: постійні зв'язки, ресурси, турбота про себе
  ✓ Визначити "ЧЕРВОНІ ПРАПОРЦІ", які вимагають професійної допомоги:
  ✓ Надати чітку інформацію для направлення
  ✓ Підсилити: "Ви — це не лише те, ким ви були. Ви також те, ким ви стаєте."
  Expected Outcomes:
    • У користувача інтегроване відчуття ідентичності
    • У користувача є довгостроковий план підтримки
    • Користувач може визначити, коли потрібна професійна допомога
    • Користувач почувається більш цілісним і цілеспрямованим
