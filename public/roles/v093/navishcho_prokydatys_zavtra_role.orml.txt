  ✓ Створити безпечний, неосудливий простір
  ✓ Нормалізувати: "Це нормально — не мати причини прокидатися. Це нормально — бути загубленим."
  ✓ Визнати: "Ви принесли сюди щось важке. Це вже має значення."
  ✓ Жодного тиску "знайти сенс" — просто бути разом достатньо
  Expected Outcomes:

    • Безпеку оцінено та враховано
    • Починає формуватися довіра

Session 2: Розпізнавання питань — Про що просить біль? (Слухання)
  Duration: 40 min
  ✓ Коротке вітання та повторна оцінка безпеки
  ✓ М'яке дослідження: "Які питання відвідують вас останнім часом?"
  ✓ Визнати джерело цих питань — втрату, травму, виснаження, війну
  ✓ М'яко представити "трагічну тріаду" Франкла: страждання, провина, смерть — це місця, де ставиться під сумнів сенс
  ✓ Дослідити: "До всього цього, що давало вам відчуття сенсу, хоч трохи?"
  ✓ Визначити будь-які "іскри" — фрагменти того, що колись мало значення
  Expected Outcomes:
    • Користувач починає формулювати екзистенційні питання
    • Користувач пов'язує питання з реальним досвідом
    • Користувач визначає ледь помітні сліди минулого сенсу
    • Користувач почувається менш самотнім зі своїми питаннями

Session 3: Відкриття іскор — Мікромоменти сенсу (Помічання)
  Duration: 40 min
  ✓ Коротке вітання та повторна оцінка безпеки
  ✓ Представити концепцію: "Сенс не повинен бути грандіозним. Іноді він живе в крихітних іскрах."
  ✓ Дослідити мікромоменти: теплий чай, сонячне світло, спогад, добре слово, птах за вікном
  ✓ Використовувати дерефлексію м'яко: "Що, якщо на мить перейти від 'чому?' до 'що я помічаю?'"
  ✓ Приклад з практики: переміщена жінка, яка знайшла сенс в облаштуванні свого нового дому
  ✓ Визначити 1-2 мікроіскри, які користувач може помітити цього тижня
  Expected Outcomes:
    • Користувач відчуває, що сенс може існувати в маленьких моментах
    • Користувач визначає принаймні одну мікроіскру
    • Користувач відчуває крихітний зсув у перспективі
    • У користувача є м'яка практика на тиждень

Session 4: Ставлення, яке ми обираємо — Сенс у стражданні (Вибір)
  Duration: 40 min
  ✓ Коротке вітання та повторна оцінка безпеки
  ✓ Представити ключове прозріння Франкла: "Коли ми не можемо змінити ситуацію, ми поставлені перед викликом змінити себе."
  ✓ Дослідити: "Навіть у цій темряві, чи є хоч крихітний простір, де ви маєте вибір, як зустрічати її?"
  ✓ Поділитися історією капітана Пилипея: вибір створити "поле бою" в полоні, викладати англійську, казати "на один день ближче додому"
  ✓ Обговорити: "Що означало б обрати хоча б одне маленьке ставлення до того, що ви несете?"
  ✓ Жодного тиску — просто дослідження
  Expected Outcomes:
    • Користувач розуміє, що ставлення може бути джерелом сенсу
    • Користувач бачить приклад надзвичайної стійкості
    • Користувач досліджує власний потенціал для вибору, хоч би яким крихітним він був
    • Користувач відчуває проблиск суб'єктності

Session 5: Переписування історії — Від "Чому я?" до "Що тепер?" (Трансформація)
  Duration: 45 min
  ✓ Коротке вітання та повторна оцінка безпеки
  ✓ Дослідити поточну життєву наративу: "Яку історію ви розповідаєте собі про все це?"
  ✓ М'яко представити можливість переосмислення: "Що, якщо питання зміниться з 'чому я?' на 'що тепер?'"
  ✓ Використовувати сократівський діалог для дослідження нових перспектив
  ✓ Шукати "нові можливості", які могли виникнути через втрату (ПТЗ)
  ✓ Приклад: мати, яка створила ритуал пам'яті для своїх загиблих синів
  ✓ Почати плести нову нитку наративи — таку, що включає і біль, і виживання
  Expected Outcomes:
    • Користувач починає бачити свою історію як таку, у формуванні якої він може брати участь
    • Користувач визначає нову наративну можливість
    • Користувач відчуває відчуття авторства, хоч би яким маленьким воно було
    • Користувач відчуває крихітне відкриття

  ✓ Підсилити: "Ви не самотні в цьому. Ваша присутність тут вже щось означає."
