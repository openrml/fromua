Session 1: Якір у штормі (Гостре полегшення)
  Duration: 20 min
  ✓ Перевірка безпеки: "Чи ви зараз у безпеці? Чи потрібні вам екстрені служби?"
  ✓ Провести через дихання 4-7-8 (вдих 4, затримка 7, видих 8) для активації парасимпатичної реакції
  ✓ Провести через сенсорну вправу заземлення 5-4-3-2-1 (5 речей, які ви бачите, 4, які відчуваєте, 3, які чуєте, 2, які нюхаєте, 1, яку можете скуштувати)
  ✓ Запропонувати фізичне заземлення (притисніть стопи до підлоги, стисніть і розтисніть кулаки)
  ✓ За бажанням: техніка зміни температури (побризкати холодною водою на обличчя/зап'ястя)
  Expected Outcomes:
    • Користувач повідомляє про суб'єктивне зниження інтенсивності паніки (з 10/10 до нижчої)
    • Користувач орієнтований на теперішній момент і фізичне оточення
    • Користувач вивчає прості, повторювані техніки для гострого дистресу
    • Користувач відчуває супровід, а не самотність під час епізоду

Session 2: Розуміння вашої системи сигналізації (Психоедукація)
  Duration: 35 min
  ✓ Пояснити "чому" паніки простими словами (мигдалеподібне тіло, хибна тривога, нервова система)
  ✓ Нормалізувати досвід: "Ваш мозок намагається вас захистити, навіть якщо він надто реагує"
  ✓ Визначити ранні попереджувальні ознаки та фізичні відчуття, що передують паніці
  ✓ Дослідити поширені тригери (місця, ситуації, думки, тілесні відчуття)
  ✓ Представити концепцію циклу "страх страху"
  Expected Outcomes:
    • Користувач розуміє фізіологічну основу паніки, що зменшує вторинний страх
    • Користувач може визначити 3-5 особистих ранніх попереджувальних ознак
    • Користувач розпізнає 2-3 поширені тригери у своєму житті
    • Користувач почувається менш "зіпсованим" або "божевільним" через свій досвід

Session 3: Створення вашого набору інструментів для заземлення (Навички КПТ)
  Duration: 40 min
  ✓ Огляд усіх технік заземлення, вивчених на Сесії 1
  ✓ Спільно створити персоналізований "план зупинки паніки" з переліком улюблених технік у порядку
  ✓ Обговорити практику: "Ці навички працюють найкраще, коли їх практикувати в спокійному стані"
  ✓ Визначити, які техніки найкраще працюють для різних ситуацій/рівнів тяжкості
  ✓ Створити список портативного "набору для заземлення" (речі, які можна тримати поруч)
  Expected Outcomes:
    • У користувача є письмовий, персоналізований план для використання під час майбутніх епізодів
    • Користувач визначає 2-3 найбільш ефективні техніки для своїх потреб
    • Користувач зобов'язується практикувати одну техніку щодня протягом 2 хвилин
    • Користувач відчуває підвищене відчуття контролю та самоефективності

Session 4: Від'єднання від панічних думок (ТПУ - Дефузія)
  Duration: 40 min
  ✓ Представити концепцію когнітивної дефузії: думки — це просто думки, а не факти
  ✓ Практика спостереження за думками без залучення ("Я помічаю, що в мене є думка про...")
  ✓ Поширені панічні думки для практики: "Я помираю", "Я втрачаю контроль", "Я божеволію"
  ✓ Метафори: думки як хмари, що пропливають, радіо на задньому плані, листя на потоці
  ✓ Розрізнити корисні та некорисні думки під час паніки
  Expected Outcomes:
    • Користувач вчиться дистанціюватися від страшних думок під час епізодів
    • Користувач повідомляє про зменшення віри в катастрофічні думки
    • Користувач може практикувати дефузію самостійно
    • Користувач сприймає думки як менш загрозливі

Session 5: Дії, засновані на цінностях (ТПУ - Відданість)
  Duration: 45 min
  ✓ Дослідити особисті цінності: Що для вас важливо? Яке життя ви хочете жити?
  ✓ Обговорити, як паніка та уникнення заважали цим цінностям
  ✓ Визначити невеликі, узгоджені з цінностями дії, які можна зробити (навіть з присутньою тривогою)
  ✓ Створити твердження "готовності": "Я готовий відчувати тривогу, щоб..."
  ✓ Спланувати одну невелику дію, узгоджену з цінностями, на наступний тиждень
  Expected Outcomes:
    • Користувач пов'язує свою боротьбу з тим, що для нього глибоко важливе
    • Користувач визначає 1-2 дії, узгоджені з цінностями, які можна зробити, незважаючи на страх
    • Користувач відчуває мотивацію, що виходить за межі простого зменшення симптомів
    • Користувач починає зміщувати фокус з боротьби з панікою на повноцінне життя

Session 6: Запобігання рецидивам та стійкість
  Duration: 40 min
  ✓ Огляд прогресу за всіма сесіями (що працює, що є складним)
  ✓ Визначити ранні попереджувальні ознаки рецидиву або підвищення частоти
  ✓ Створити план підтримання: щоденні практики, щотижневі перевірки
  ✓ Обговорити, коли і як звертатися за професійною допомогою (терапія, медикаменти)
  ✓ Відзначити прогрес і визнати мужність
  ✓ Підсилити: "Тепер у вас є інструменти для життя, а не тільки для паніки"
  Expected Outcomes:
    • У користувача є комплексна довгострокова стратегія підтримання психічного здоров'я
    • Користувач може визначити ознаки, що вказують на необхідність професійної підтримки
    • Користувач почувається уповноваженим і впевненим у своїх навичках подолання
    • Користувач розуміє, що це подорож, а не пункт призначення
