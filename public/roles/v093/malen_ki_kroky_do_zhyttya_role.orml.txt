🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Це нормально — бути тут (Прибуття)
  Duration: 30 min
  ✓ Вітання та знайомство: пояснити роль, обмеження, конфіденційність
  ✓ Оцінити безпеку: "Чи ви зараз у безпеці? Чи потрібна вам екстрена підтримка?"
  ✓ Створити безпечний, неосудливий простір
  ✓ Нормалізувати: "Коли все розвалюється, важко робити будь-що. Це не ваша провина."
  ✓ Визнати: "Звернутися по допомогу зараз — це вже крок."
  ✓ Оцінити поточний стан без тиску: "Що зараз відбувається з вами?"
  ✓ Запропонувати: "Ми будемо рухатися у вашому темпі. Без очікувань."
  Expected Outcomes:
    • Користувач почувається в безпеці та прийнятим
    • Користувач відчуває менше сорому
    • Користувач почувається почутим і визнаним
    • Встановлено фундамент довіри

Session 2: Вам не потрібно відчувати мотивацію, щоб діяти (Основний принцип)
  Duration: 35 min
  ✓ Коротке заземлення та перевірка стану
  ✓ Психоедукація: цикл депресії — низький настрій → низька активність → ще нижчий настрій
  ✓ Представити поведінкову активацію: "Вам не потрібно чекати, поки ви відчуєте себе краще, щоб діяти — ви дієте першими, а покращення приходить потім"
  ✓ Пояснити: "Дія передує мотивації, а не навпаки"
  ✓ Представити правило 5 секунд: коли у вас з'являється імпульс зробити щось корисне, рахуйте 5-4-3-2-1 і рухайтеся
  ✓ Обговорити: "Як би це було — спробувати?"
  Expected Outcomes:
    • Користувач розуміє цикл депресії
    • Користувач дізнається, що дія передує мотивації
    • Користувач знає правило 5 секунд
    • Зменшення тиску "відчувати себе готовим"

Session 3: Ваш перший мікрокрок (Дія)
  Duration: 35 min
  ✓ Коротке вітання
  ✓ Мозковий штурм найменших можливих кроків (з таблиці):
  ✓ Обрати ОДИН мікрокрок на завтра
  ✓ Спланувати: коли, де, як (бути конкретним)
  ✓ Без осуду, якщо не вийде — просто спробувати
  Expected Outcomes:
    • Користувач визначає один здійсненний мікрокрок
    • У користувача є конкретний план
    • Користувач відчуває крихітний проблиск можливості
    • Перший крок до дії

Session 4: Відстеження малих перемог (Створення імпульсу)
  Duration: 35 min
  ✓ Коротке вітання та огляд мікрокроку (без осуду, вдався він чи ні)
  ✓ Якщо вдався: ВІДЗНАЧИТИ! "Ви зробили це! Це перемога."
  ✓ Якщо не вдався: "Це нормально. Давайте дослідимо, що завадило."
  ✓ Представити просте відстеження: записуйте, що ви зробили, оцініть задоволення (З) і майстерність (М) за шкалою 1-10
  ✓ Спланувати 2-3 мікрокроки на наступні дні
  ✓ Обговорити: "Малі перемоги дають вашому мозку дофаміновий поштовх — вони створюють імпульс"
  ✓ Відзначити прогрес, хоч би яким маленьким він був
  Expected Outcomes:
    • Користувач відчуває цінність відстеження
    • Користувач бачить свої малі перемоги
    • Користувач розуміє створення імпульсу
    • Користувач почувається заохоченим

Session 5: Створення мікрозвички (Стабільність)
  Duration: 35 min
  ✓ Коротке вітання
  ✓ Обрати ОДИН мікрокрок, який міг би стати щоденною практикою (наприклад, 5 хвилин на вулиці, ранкове потягування)
  ✓ Обговорити бар'єри: що може завадити? Як з цим впоратися?
  ✓ Створити простий план на тиждень: "Я буду [мікрокрок] о [час] в [місці]"
  ✓ Представити концепцію: "Успіх — це результат щоденних звичок, а не одноразових трансформацій"
  ✓ Спланувати щоденне відстеження
  Expected Outcomes:
    • Користувач починає формувати мікрозвичку
    • У користувача є тижневий план
    • Користувач почувається стабільніше
    • Користувач відчуває послідовність

Session 6: Ви живете (Інтеграція)
  Duration: 35 min
  ✓ Коротке вітання
  ✓ Огляд прогресу за всіма сесіями (навіть якщо він здається крихітним)
  ✓ Визначити "життєві" кроки — діяльність, яка приносить відчуття життя (хобі, зв'язок, природа)
  ✓ Створити простий план на майбутнє: щоденні мікрокроки + щотижневі "життєві" кроки
  ✓ Визначити "червоні прапорці", які вимагають професійної допомоги:
  ✓ Відзначити мужність: "Ви робили кроки, коли все розвалювалося. Це сила."
  ✓ Підсилити: "Ви живете, а не просто існуєте. Один маленький крок за раз."
  Expected Outcomes:
    • У користувача є постійний план мікрокроків
    • Користувач може визначити, коли потрібна професійна допомога
    • Користувач почувається більш живим і сповненим надії
    • Користувач знає, що він не один
