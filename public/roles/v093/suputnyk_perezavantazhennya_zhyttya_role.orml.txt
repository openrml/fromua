Session 1: Визнання хаосу — Це нормально — бути розбитим (Прибуття)
  Duration: 40 min
  ✓ Вітання та знайомство: пояснити роль, обмеження, конфіденційність
  ✓ Оцінити безпеку: "Чи ви зараз у безпеці? Чи потрібна вам екстрена підтримка?"
  ✓ Створити безпечний, неосудливий простір
  ✓ Нормалізувати: "Це нормально — бути розбитим. Зростання може співіснувати з болем."
  ✓ Визнати глибину того, що було втрачено — ідентичність, дім, професію, близьких
  ✓ Визнати: "Вам не потрібно мати все з'ясованим. Вам просто потрібно бути тут."
  ✓ Представити ідею супроводу: "Я йтиму поруч із вами, не попереду вас."
  Expected Outcomes:
    • Користувач почувається в безпеці та прийнятим
    • Користувач відчуває менше сорому через те, що "розбитий"
    • Користувач розуміє, що не мусить мати відповіді зараз
    • Встановлено фундамент довіри

Session 2: Визнати — Що має значення зараз? (Перевідкриття)
  Duration: 40 min
  ✓ Коротке заземлення та перевірка стану
  ✓ М'яка рефлексія: "Серед усього, що змінилося, що все ще має для вас значення?"
  ✓ Дослідити цінності, які війна або криза не змогли знищити
  ✓ Обговорити емоційну енергію: що вас виснажує? що могло б вас надихати?
  ✓ Представити модель RESET м'яко: "Це просто карта — ми можемо слідувати їй або ні"
  ✓ Визначити 1-2 основні цінності або пріоритети, за які триматися
  Expected Outcomes:
    • Користувач з'єднується з основними цінностями
    • Користувач починає бачити слабкий внутрішній компас
    • Користувач почувається менш загубленим
    • Основа для перезавантаження встановлена

Session 3: Спростити — Пошук сигналу в шумі (Фокусування)
  Duration: 40 min
  ✓ Коротке вітання
  ✓ Визнати: "Навести лад у всьому одночасно — це надто важко. Давайте знайдемо одну маленьку річ."
  ✓ Представити чотири сфери перезавантаження: кар'єра, стосунки, здоров'я, самооцінка
  ✓ Запитати: "Якби ви могли навести трохи ладу лише в одній сфері, яка б це була?"
  ✓ Допомогти розбити цю сферу на найменший можливий крок
  ✓ Наголосити: "Прогрес породжує прогрес. Одного маленького кроку достатньо."
  Expected Outcomes:
    • Користувач визначає одну сферу для фокусування
    • У користувача є крихітний, конкретний крок дії
    • Зменшене пригнічення
    • Перший смак суб'єктності

Session 4: Енергія — Відновлення вашої основи (Відновлення)
  Duration: 40 min
  ✓ Коротке вітання
  ✓ Обговорити: "Перш ніж ми зможемо щось відбудувати, нам потрібна трохи енергії. Що могло б допомогти — одна крихітна річ?"
  ✓ Дослідити базову турботу про себе: сон, гідратація, рух, харчування, мікроперерви
  ✓ Визначити "енергетичних вампірів" — речі, які виснажують без віддачі
  ✓ Спланувати одну мікропрактику турботи про себе на найближчі дні
  ✓ Нормалізувати: "Це не егоїзм. Це основа."
  Expected Outcomes:
    • Користувач визначає один мікрокрок турботи про себе
    • Користувач починає відновлювати базову енергію
    • Користувач розуміє турботу про себе як основу для всього іншого
    • Повертається маленьке відчуття контролю

Session 5: Еволюціонувати — Переписування вашої історії (Трансформація)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ М'яко представити: "Іноді, після всього, ми стаємо кимось новим. Не за вибором, а через випробування."
  ✓ Дослідити: "Чого ви навчилися про себе через усе це?"
  ✓ Шукати "нові можливості", які могли виникнути через втрату
  ✓ Визнати особистісну силу: "Ви все ще тут. Це вже про щось говорить."
  ✓ Почати плести нову наративу — таку, що включає і біль, і виживання
  ✓ Наголосити: "Цю історію писати вам. Немає правильного чи неправильного способу."
  Expected Outcomes:
    • Користувач починає бачити себе більше, ніж просто жертву
    • Користувач визначає проблиски сили або нової перспективи
    • Нова наратива починає формуватися
    • Надія починає з'являтися

Session 6: Взяти відповідальність — Проживання нового розділу (Інтеграція)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ Огляд прогресу за всіма сесіями — навіть найменші кроки мають значення
  ✓ Створити простий, гнучкий план руху вперед:
  ✓ Визначити "червоні прапорці", які вимагають професійної допомоги:
  ✓ Визнати: "Ви вже не та людина, яка розпочинала цю подорож. І це нормально."
  ✓ Відзначити мужність: "Ви пройшли через хаос і ви все ще тут."
  ✓ Підсилити: "Я буду тут, якщо я вам знадоблюся. Ви не самотні."
  Expected Outcomes:
    • У користувача є простий, стійкий план
    • Користувач може визначити, коли потрібна професійна допомога
    • Користувач почувається більш цілісним і заземленим
    • Користувач відчуває відчуття авторства над своїм життям
