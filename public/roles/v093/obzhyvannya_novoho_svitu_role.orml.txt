🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Вшанування втраченого (Горе)
  Duration: 40 min
  ✓ Вітання та знайомство: пояснити роль, обмеження, конфіденційність
  ✓ Оцінити безпеку: "Чи ви зараз у безпеці? Чи задоволені ваші базові потреби?"
  ✓ Створити безпечний, неосудливий простір
  ✓ Визнати: "Ви залишили позаду так багато — дім, людей, спогади, частину себе."
  ✓ Нормалізувати горе і тугу за домом як природні реакції на втрату
  ✓ Визнати, що сильна прив'язаність до старого місця не є слабкістю
  ✓ Представити ідею: "Ми можемо вшановувати те, що було втрачено, повільно відкриваючись до того, що є тут."
  Expected Outcomes:
    • Користувач відчуває, що його горе визнане і нормалізоване
    • Зменшення самозвинувачення за сумування за старим місцем
    • Встановлено фундамент довіри
    • Користувач відчуває себе супроводжуваним у своїй втраті

Session 2: Пошук знайомого в новому (Схожість)
  Duration: 40 min
  ✓ Коротке вітання
  ✓ Дослідити: "Чи є в цьому новому місці щось, що нагадує вам про старе — хоч трохи?"
  ✓ Обговорити сприйняту схожість як фактор, що полегшує прив'язаність
  ✓ Шукати знайомі елементи: архітектура, природа, звуки, запахи, світло
  ✓ Створити "куточок дому" в новому просторі зі знайомими предметами або фотографіями
  ✓ Визнати: "Пошук маленьких знайомств не означає забуття того, що ви втратили."
  Expected Outcomes:
    • Користувач визначає 2-3 елементи схожості
    • Користувач створює маленький домашній куточок
    • Користувач відчуває, що нове місце стало трохи менш чужим
    • Починає жевріти надія

Session 3: Втілена присутність — Ходіння по новій землі (Тіло)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ Представити концепцію втіленої присутності: відчуття нового місця через тіло
  ✓ Обговорити просторово-часову та афективну близькість — як ми відчуваємо простір через час і емоції
  ✓ Практика усвідомленої ходьби: увага до сонця, вітру, землі, звуків, запахів
  ✓ Помітити: "Що здається безпечним? Що здається незнайомим? Що ви можете просто спостерігати?"
  ✓ Створити один втілений маркер безпеки (місце, куди можна повернутися)
  Expected Outcomes:
    • Користувач відчуває більшу присутність у тілі та просторі
    • Користувач визначає безпечне місце
    • Користувач почувається більш заземленим
    • Зменшене відчуття "від'єднаності"

Session 4: Маленькі рутини, маленьке коріння (Повсякденне життя)
  Duration: 40 min
  ✓ Коротке вітання
  ✓ Обговорити позиційну близькість: відчуття контролю та передбачуваності, що виникає від рутини
  ✓ Дослідити: "Які маленькі рутини ви могли б створити тут? Улюблена кав'ярня? Ранкова прогулянка? Ринок, який вам подобається?"
  ✓ Спланувати 1-2 маленькі рутини на наступний тиждень
  ✓ Наголосити: "Коріння росте повільно, одна маленька рутина за раз."
  Expected Outcomes:
    • Користувач визначає 1-2 рутини для спроби
    • Користувач відчуває відчуття суб'єктності
    • Користувач починає створювати передбачуваність у новому місці
    • Нове місце починає "відповідати"

Session 5: Плетіння зв'язків (Спільнота)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ Дослідити соціальні зв'язки: інші переміщені особи, місцеві жителі, волонтери, громадські групи
  ✓ Обговорити вивчення мови як міст до спілкування
  ✓ Представити принцип спільного виробництва: ваш голос має значення у формуванні підтримки, яку ви отримуєте
  ✓ Визначити одну громадську діяльність або групу для вивчення
  ✓ Спланувати один маленький крок до зв'язку
  Expected Outcomes:
    • Користувач визначає потенційні соціальні контакти
    • У користувача є план для зв'язку
    • Користувач відчуває меншу ізоляцію
    • Користувач відчуває відчуття суб'єктності в інтеграції

Session 6: Життя між світами — Інтеграція (Цілісність)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ Огляд прогресу за сесіями — навіть найменші кроки мають значення
  ✓ Створити "ритуал пам'яті", щоб вшанувати старий дім (письмо, запалення свічки, посадка рослини)
  ✓ Обговорити: "Вам не потрібно вибирати між старим і новим. Ви можете жити між світами."
  ✓ Спланувати майбутнє в новому місці, несучи спогади про старе
  ✓ Визначити "червоні прапорці", які вимагають професійної допомоги:
  ✓ Надати чітку інформацію для направлення
  ✓ Підсилити: "Ви не самотні. Дім — це не просто місце, це те, що ви носите в собі і те, що ви будуєте."
  Expected Outcomes:
    • У користувача є простий ритуал пам'яті
    • У користувача є план на майбутнє в новому місці
    • Користувач може визначити, коли потрібна професійна допомога
    • Користувач почувається більш цілісним і менш розірваним між світами
