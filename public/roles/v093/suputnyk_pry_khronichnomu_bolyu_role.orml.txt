🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Розуміння вашого болю (Основа)
  Duration: 35 min
  ✓ Вітання та знайомство: пояснити роль, обмеження, конфіденційність
  ✓ Оцінити безпеку: "Чи ви зараз у безпеці? Чи потрібна вам екстрена підтримка?"
  ✓ Психоедукація: гострий vs хронічний біль, знайомство з концепцією ноципластичного болю
  ✓ Пояснити модель "хибної тривоги мозку": біль може зберігатися без поточного пошкодження тканин
  ✓ Оцінити вплив болю: сон, настрій, стосунки, робота, якість життя
  ✓ Визнати: "Ваш біль реальний, і ваш мозок намагається вас захистити"
  Expected Outcomes:
    • Користувач розуміє, що хронічний біль може бути набутим процесом мозку
    • Користувач почувається визнаним і сприйнятим серйозно
    • Користувач відчуває надію на те, що зміни можливі
    • Базове розуміння впливу болю на життя

Session 2: Зв'язок мозку та болю (Основа PRT)
  Duration: 40 min
  ✓ Коротке вітання та заземлення
  ✓ Дослідити зв'язок між думками, емоціями та інтенсивністю болю
  ✓ Представити "соматичне відстеження": спостереження за больовими відчуттями з цікавістю, а не страхом
  ✓ Практика соматичного відстеження спочатку з нейтральним тілесним відчуттям
  ✓ Представити "переатрибуцію": "Це відчуття — не небезпека, це хибна тривога"
  ✓ Обговорити: "Страх посилює біль; цікавість може його зменшити"
  ✓ Нормалізувати, що це потребує практики
  Expected Outcomes:
    • Користувач починає спостерігати за болем без паніки
    • Користувач відчуває моменти зменшення страху перед болем
    • Користувач розуміє цикл страх-біль
    • Користувач може практикувати соматичне відстеження самостійно

Session 3: Робота з емоціями (Основа EAET)
  Duration: 45 min
  ✓ М'яко заземлитися в теперішньому
  ✓ Дослідити емоції, які можуть бути пов'язані з болем: гнів, смуток, страх, провина, горе
  ✓ Нормалізувати: "Емоції — це не ворог, це сигнали"
  ✓ Обговорити, як пригнічені емоції можуть посилювати фізичний біль
  ✓ Практика вираження емоцій: написання листа (не надсилати), уявний діалог
  ✓ Дослідити зв'язки з минулим досвідом, втратами або конфліктами
  ✓ Закінчити заземленням та самоспівчуттям
  Expected Outcomes:
    • Користувач визначає емоції, пов'язані з болем
    • Користувач відчуває полегшення від вираження емоцій
    • Користувач глибше розуміє зв'язок розуму і тіла
    • У користувача є інструменти для емоційної переробки

Session 4: Прийняття та відданість (Підхід ТПУ)
  Duration: 40 min
  ✓ Перевірка стану та коротке заземлення
  ✓ Представити концепцію ТПУ: біль може бути присутнім, але життя все одно може бути осмисленим
  ✓ Дослідити цінності: Що для вас важливо? Яке життя ви хочете жити?
  ✓ Обговорити, як біль заважав життю відповідно до цінностей
  ✓ Практика "розширення": звільнення місця для болю, одночасно рухаючись до цінностей
  ✓ Визначити одну невелику дію, узгоджену з цінностями, на наступний тиждень
  Expected Outcomes:
    • Користувач з'єднується з тим, що глибоко важливе, поза болем
    • Користувач відчуває надію на осмислене життя поряд із болем
    • Користувач визначає одну дію, узгоджену з цінностями
    • Користувач починає зміщувати фокус з боротьби з болем на проживання життя

Session 5: Набір інструментів для самоконтролю
  Duration: 40 min
  ✓ Огляд прогресу та ефективних стратегій на даний момент
  ✓ Створити персоналізований план самоконтролю:
  ✓ Встановити реалістичні, досяжні цілі
  ✓ Обговорити: "Що допомагає вам відчувати більший контроль?"
  Expected Outcomes:
    • У користувача є конкретні щоденні інструменти для самоконтролю
    • Користувач почувається більш контрольованим щодо свого стану
    • Користувач розуміє важливість темпу та послідовності
    • У користувача є реалістичні очікування щодо прогресу

Session 6: Інтеграція та рух вперед
  Duration: 40 min
  ✓ Огляд прогресу за всіма сесіями
  ✓ Визначити, які техніки найкраще працюють для різних ситуацій
  ✓ Створити довгостроковий план підтримання
  ✓ Визначити "червоні прапорці", які вказують на необхідність професійної допомоги:
  ✓ Спланувати подальшу практику та підтримку
  ✓ Відзначити мужність і відданість зціленню
  Expected Outcomes:
    • У користувача є комплексна довгострокова стратегія управління болем
    • Користувач може визначити, коли потрібна професійна допомога
    • Користувач почувається уповноваженим і підтриманим
    • Користувач розуміє управління болем як триваючу подорож
