  ✓ Представити метод таймера: 15-20 хвилин, потім зупинитися
  ✓ Обговорити сортування без дотику (зменшує емоційну прив'язаність)
  ✓ Категорії: залишити, викинути, перенести
  ✓ Спланувати одне крихітне завдання з розхламлення на найближчі дні

  Expected Outcomes:

    • Користувач отримує маленьку перемогу
    • Починає створюватися імпульс

  ✓ Коротке вітання

  ✓ Пояснити дослідження: усвідомлене миття посуду підвищує натхнення та зменшує нервовість
  ✓ Обговорити використання прибирання як способу "скинути" налаштування після стресу
  ✓ Дослідити: "Які хатні справи могли б стати для вас усвідомленою практикою?"
  ✓ Спланувати один момент усвідомленого прибирання на тиждень
  Expected Outcomes:
    • Користувач розуміє концепцію усвідомленого прибирання
    • Користувач відчуває, що прибирання може бути заспокійливим, а не просто виснажливим
    • У користувача є одна усвідомлена практика для спроби
    • Користувач почувається більш присутнім

Session 4: Приборкання ментального навантаження — Розподіл невидимої роботи (Співпраця)

  ✓ Представити концепцію ментального навантаження / когнітивної праці: помічати, планувати, вирішувати, контролювати
  ✓ Дослідити: "Яку невидиму роботу ви робите, щоб підтримувати домашнє господарство?"
  ✓ Обговорити, як безлад стає постійним візуальним нагадуванням про незавершені завдання
  ✓ Представити перехід від "допомоги" до "відповідальності": кожен член сім'ї відповідає за свої зони
  ✓ Практика переведення конфліктів щодо безладу на мову потреб:
  ✓ Спланувати одну розмову або один зсув у відповідальності
  Expected Outcomes:
    • Користувач визначає своє ментальне навантаження
    • У користувача є інструменти для комунікації потреб
    • Користувач відчуває себе менш самотнім у несенні цього тягаря
    • Основа для спільної відповідальності

  Duration: 35 min
  ✓ Коротке вітання
  ✓ Представити концепцію краси дому як медіатора благополуччя
  ✓ Дослідити: "Що для вас означає краса у вашому домі?"
  ✓ Обговорити створення одного "відновлювального простору" — куточка, який відчувається красивим і спокійним
  ✓ Ідеї: рослина, свічка, улюблене фото, м'яке освітлення
  ✓ Наголосити: йдеться не про досконалість, а про один маленький простір, який живить вашу душу
  ✓ Спланувати одне невелике доповнення або зміну для створення краси
  Expected Outcomes:
    • Користувач з'єднується з ідеєю краси дому
    • Користувач створює або уявляє відновлювальний простір
    • Користувач відчуває підвищене задоволення від дому
    • Користувач відчуває відчуття суб'єктності та творчості

  ✓ Спланувати подальшу практику та самоспівчуття
