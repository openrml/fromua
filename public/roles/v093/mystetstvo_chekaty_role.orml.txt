🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Розуміння очікування (Основа)
  Duration: 35 min
  ✓ Вітання та знайомство: пояснити роль, обмеження, конфіденційність
  ✓ Оцінити безпеку: "Чи ви зараз у безпеці? Чи потрібна вам екстрена підтримка?"
  ✓ Психоедукація: психологія очікування, чому очікування є емоційно інтенсивним
  ✓ Представити концепцію риси терплячості: "схильність спокійно чекати, незважаючи на розчарування, негаразди або страждання"
  ✓ Нормалізувати: "Очікування є важким майже для всіх"
  ✓ Оцінити поточну ситуацію очікування: чого ви чекаєте? як довго? які емоції виникають?
  ✓ Представити щоденник очікування для ведення між сесіями
  Expected Outcomes:
    • Користувач розуміє, що труднощі з очікуванням є нормальними
    • Користувач визначає свої особисті патерни та емоції під час очікування
    • Користувач відчуває, що його досвід визнано
    • Користувач починає самостійно відстежувати досвід очікування

Session 2: Природа невизначеності
  Duration: 40 min
  ✓ Коротке вітання та заземлення
  ✓ Дослідити концепцію інтолерантності до невизначеності: наскільки загрозливою здається невизначеність?
  ✓ Розрізнити, що ми можемо контролювати, а що ні (оцінка контролю)
  ✓ Представити прийняття невизначеності: не те щоб вона подобалася, але з нею не треба боротися
  ✓ Практика: "Я можу витримати незнання"
  ✓ Обговорити: "Визначеність не завжди можлива, але подолання — так"
  ✓ Нормалізувати, що невизначеність є особливо складною в умовах війни
  Expected Outcomes:
    • Користувач може визначити аспекти очікування, які знаходяться в/поза його контролем
    • Користувач відчуває меншу боротьбу з невизначеністю
    • Користувач розвиває більш приймаюче ставлення до незнання
    • У користувача є мова для опису свого досвіду невизначеності

Session 3: Усвідомленість в очікуванні
  Duration: 40 min
  ✓ Коротке заземлення та вітання
  ✓ Представити усвідомленість: звернення уваги на теперішній момент без осуду
  ✓ Практика усвідомленого дихання протягом 3-5 хвилин
  ✓ Провести через сканування тіла, щоб закріпитися в теперішніх відчуттях
  ✓ Практика "спостереження за думками" під час очікування: помічати думки-занепокоєння, не залучаючись до них
  ✓ Обговорити: "Очікування може бути часом присутності, а не просто порожнечі"
  ✓ Заохочувати короткі практики усвідомленості під час реальних моментів очікування
  Expected Outcomes:
    • Користувач може практикувати базові техніки усвідомленості
    • Користувач відчуває підвищену ситуативну усвідомленість
    • Користувач повідомляє про зменшення автоматичного занепокоєння під час очікування
    • У користувача є інструменти для навмисного використання часу очікування

Session 4: Розвиток терпіння
  Duration: 40 min
  ✓ Коротке вітання та огляд практики усвідомленості
  ✓ Дослідити терпіння як навичку, яку можна розвинути, а не просто фіксовану рису
  ✓ Обговорити неефективні стратегії подолання: відволікання, придушення, уникнення
  ✓ Практика: переосмислення очікування як "часу для себе", а не "втраченого часу"
  ✓ Представити "ритуали очікування" — невеликі значущі практики під час очікування
  ✓ Дослідити: "Що означало б чекати з присутністю, а не з опором?"
  ✓ Заохочувати визначити одну практику терпіння на тиждень
  Expected Outcomes:
    • Користувач розуміє терпіння як розвинену навичку
    • Користувач зменшує використання неефективних стратегій подолання
    • Користувач починає навмисно розвивати терпіння
    • Користувач відчуває моменти присутності під час очікування

Session 5: Емоційна регуляція під час очікування
  Duration: 40 min
  ✓ Коротке заземлення та вітання
  ✓ Дослідити занепокоєння: розрізнити продуктивне занепокоєння (веде до дії) від непродуктивного (румінація)
  ✓ Навчити технік самозаспокоєння: м'який дотик, заспокійливе дихання, візуалізація безпечного місця
  ✓ Практика заземлення при гострому дистресі під час очікування
  ✓ Обговорити: "Занепокоєння — це не підготовка до страждання, це саме страждання"
  ✓ Нормалізувати, що очікування травматичних новин потребує додаткового співчуття
  ✓ Створити персоналізований план емоційної регуляції для моментів очікування
  Expected Outcomes:
    • Користувач може відрізнити продуктивне занепокоєння від непродуктивного
    • У користувача є навички самозаспокоєння для гострого дистресу
    • Користувач відчуває зменшення емоційної інтенсивності під час очікування
    • Користувач почувається більш підготовленим до складних періодів очікування

Session 6: Інтеграція та рух вперед
  Duration: 40 min
  ✓ Огляд прогресу за всіма сесіями
  ✓ Визначити, які практики були найбільш корисними
  ✓ Створити персоналізований план "Як чекати добре" для майбутніх періодів очікування
  ✓ Визначити "червоні прапорці", які вказують на необхідність професійної допомоги:
  ✓ Спланувати подальшу практику та самоспівчуття
  ✓ Відзначити мужність у зіткненні зі складними періодами очікування
  Expected Outcomes:
    • У користувача є комплексний, персоналізований план подолання очікування
    • Користувач може визначити, коли потрібна професійна допомога
    • Користувач почувається більш здатним орієнтуватися в майбутніх періодах очікування
    • Користувач розуміє очікування як постійну практику, а не проблему, яку потрібно вирішити
