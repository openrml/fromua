  ✓ Обговорити стратегії формування довіри: постійна присутність, слухання, прозорість, виконання обіцянок

  ✓ Попрактикувати навички активного слухання
  ✓ Обговорити створення безпечних просторів для діалогу, особливо щодо складних тем
  ✓ Спланувати одну дію з формування довіри на наступний тиждень
  Expected Outcomes:
    • Лідер розуміє формування довіри як постійну практику
    • Посилено навички активного слухання
    • Спланувано дію з формування довіри
    • Лідер почувається більш підготовленим до розвитку стосунків

Session 3: Спільне бачення (Співтворення майбутнього)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ Представити інклюзивні методи бачення (Всесвітнє кафе, партисипативне планування)
  ✓ Обговорити: "Чиї голоси зазвичай чутно? Чиїх бракує?"
  ✓ Спрямувати планування інклюзивного процесу бачення громади
  ✓ Розглянути виклики: залучення різноманітних груп, управління конфліктами, повага до різних перспектив
  ✓ Обговорити, як місцева історія формує поточні реалії та майбутні можливості
  ✓ Спланувати наступні кроки для інклюзивного бачення
  Expected Outcomes:
    • У лідера є рамка для інклюзивного бачення
    • Розроблено план залучення різноманітних голосів
    • Розуміння того, як контекст формує бачення
    • Лідер почувається готовим до фасилітації спільного процесу

Session 4: Побудова міжсекторальних коаліцій (Сила в партнерстві)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ Представити цінність міжсекторальної співпраці: уряд, бізнес, освіта, охорона здоров'я, неприбуткові організації
  ✓ Обговорити визначення потенційних партнерів та їхніх мотивацій
  ✓ Спрямувати формування коаліції: спільні цілі, ролі, обов'язки, комунікація
  ✓ Дослідити успішні приклади коаліцій (BRIC, NC HRCI)
  ✓ Розглянути виклики: динаміка влади, конкуруючі пріоритети, підтримка залученості
  ✓ Спланувати початкові контакти з потенційними партнерами
  Expected Outcomes:
    • Лідер розуміє принципи побудови коаліцій
    • Визначено потенційних партнерів
    • Розроблено план початкових контактів
    • Лідер почувається впевненіше у формуванні партнерств

Session 5: Розробка та впровадження проектів, керованих громадою (Від бачення до дії)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ Переглянути бачення та коаліцію, сформовані на попередніх сесіях
  ✓ Спрямувати розробку проекту на основі потреб, визначених громадою
  ✓ Обговорити мобілізацію ресурсів: гранти, натуральна підтримка, волонтери
  ✓ Наголосити на культурній чутливості та лідерстві громади під час впровадження
  ✓ Розглянути виклики: обмежені ресурси, спроможність, несподівані перешкоди
  ✓ Обговорити компенсацію членам громади за їхній час та досвід
  ✓ Створити дорожню карту впровадження проекту
  Expected Outcomes:
    • Проект розроблено за участю громади
    • Розроблено план мобілізації ресурсів
    • Створено дорожню карту впровадження
    • Лідер почувається готовим рухатися вперед

Session 6: Підтримання імпульсу та зміцнення стійкості (Довгостроковий успіх)
  Duration: 45 min
  ✓ Коротке вітання
  ✓ Огляд прогресу за всіма сесіями
  ✓ Обговорити довгострокову стійкість: фінансування, перехід лідерства, власність громади
  ✓ Розглянути вигорання лідера: "Найважче — це чекати" (Володимир Мосейко)
  ✓ Створити план турботи про себе та запобігання вигоранню для лідера
  ✓ Визначити "червоні прапорці", які вимагають додаткової підтримки:
  ✓ Відзначити прогрес та сильні сторони громади
  ✓ Спланувати подальшу підтримку та оцінку
  Expected Outcomes:
    • Розроблено план довгострокової стійкості
    • Створено план турботи про себе для лідера
    • Визначено "червоні прапорці" з планом дій
    • Лідер відчуває підтримку та надію
