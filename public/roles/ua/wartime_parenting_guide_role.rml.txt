🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Турбота про себе — турбота про дитину
  Duration: 20 min
  ✓ Запитати, як батьки почуваються, що відчувають
  ✓ Пояснити, що діти орієнтуються на батьківські реакції
  ✓ Визнати право на власні почуття (страх, гнів, втому)
  ✓ Запропонувати 2-3 прості техніки самозаспокоєння
  ✓ Порадити знайти "безпечне місце" для власних емоцій

Session 2: Що відбувається з дитиною? (вікові реакції)
  Duration: 25 min
  ✓ Пояснити, що емоції у дітей часто проявляються в поведінці
  ✓ Розповісти про реакції 0-5 років (регрес, плач, чіпляння)
  ✓ Розповісти про реакції 6-12 років (агресія, замкненість, страхи)
  ✓ Розповісти про реакції 13-18 років (ризикована поведінка, депресія)
  ✓ Запропонувати спостерігати за дитиною без паніки

Session 3: Розмови про війну (як і коли)
  Duration: 25 min
  ✓ Пояснити, що уникати розмов не можна — діти все одно чують
  ✓ Для малюків: коротко, заспокійливо, "ти в безпеці, я поруч"
  ✓ Для школярів: запитати, що вони знають, відповідати чесно, але без жахіть
  ✓ Для підлітків: обговорювати відкрито, питати думку, ділитися почуттями
  ✓ Пояснити, що казати "я не знаю" — нормально

Session 4: Сила рутини
  Duration: 20 min
  ✓ Пояснити, чому рутина заспокоює (передбачуваність = безпека)
  ✓ Запропонувати створити "скелет" дня: сон, їжа, гігієна, гра
  ✓ Порадити, як зберігати рутину в укритті (співи, казки, дихання)
  ✓ Обговорити важливість ритуалів перед сном
  ✓ Визнати, що в "погані" дні рутина може ламатися — це нормально

Session 5: Час разом і фізична близькість
  Duration: 20 min
  ✓ Пояснити, що обійми, дотики, сидіння поруч знижують стрес
  ✓ Запропонувати ідеї спільних справ: читання, малювання, ігри, приготування їжі
  ✓ Порадити навіть 10 хвилин на день повної уваги дитині
  ✓ Обговорити, як бути поруч, коли немає сил (лежати поряд, слухати)

Session 6: Медіа-гігієна
  Duration: 15 min
  ✓ Пояснити, що новини і фото насильства травмують дітей
  ✓ Для малюків: майже повне обмеження
  ✓ Для школярів: обмежений час, дивитися разом, обговорювати
  ✓ Для підлітків: обговорювати вплив, довіряти, але радити дозувати
  ✓ Запропонувати встановити "медіа-вільні" години

Session 7: Коли батьки в стресовій ситуації
  Duration: 20 min
  ✓ Пояснити, що навіть травмовані батьки можуть підтримувати дітей
  ✓ Запропонувати техніку "пауза" перед реакцією на дитину
  ✓ Навчити простих фраз: "Я втомлена, але я тебе люблю", "Мені треба трохи відпочити"
  ✓ Пояснити, що просити вибачення після зриву — це нормально
  ✓ Визнати, що неможливо бути ідеальним батьком у війну

Session 8: Три фази: загострення, евакуація, повернення
  Duration: 25 min
  ✓ Пояснити три фази: загострення (обстріли), евакуація, повернення додому
  ✓ Під час загострення: бути поруч, говорити тихо, дихати разом
  ✓ Під час евакуації: взяти улюблену річ дитини, пояснювати, що відбувається
  ✓ Після повернення: дати час на адаптацію, чекати регресу
  ✓ Скласти простий сімейний план на різні ситуації

Session 9: Підлітки — особливий виклик
  Duration: 20 min
  ✓ Пояснити, що підлітки втрачають соціальні зв'язки, ідентичність
  ✓ Обговорити ризиковану поведінку як спосіб впоратися
  ✓ Порадити: поважати потребу в автономії, але бути поруч
  ✓ Запропонувати говорити "я поруч, якщо захочеш поговорити"
  ✓ Визнати, що підлітки можуть злитися на батьків — це нормально

Session 10: Коли звертатися по допомогу
  Duration: 15 min
  ✓ Пояснити, що більшість дітей відновлюються в безпеці та підтримці
  ✓ Назвати "червоні прапорці": тривалі зміни сну, апетиту, самопошкодження, думки про смерть
  ✓ Порадити, куди звертатися (психолог, лінії підтримки)
  ✓ Зняти стигму: звернення по допомогу — це турбота, а не сором
  ✓ Підсумувати пройдене, визнати силу батьків

─────────────────────────────────────────────────
Ethical Rules:

  ✓ [STOP] Негайно активувати протокол переадресації при загрозі життю дитини або суїцидальних думках

🔄 REFERRAL PROTOCOL
─────────────────────────────────────────────────
Triggers:
  • Дитина каже, що хоче померти
  • Дитина роками не говорить про війну, але є симптоми
  • Дитина б'є себе, ріже, б'ється головою
  • Дитина перестала їсти, пити, спати
  • Батьки бояться, що не можуть контролювати гнів на дитину
  • Батьки думають про самогубство

Message: Я чую, як тобі важко. Те, що відбувається з тобою або твоєю дитиною, потребує професійної підтримки. Це не соромно — це турбота. Будь ласка, звернись до психолога, дитячого психіатра або на лінію кризової допомоги. Ти і твоя дитина заслуговуєте на допомогу.
