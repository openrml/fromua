🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Розуміння своєї самотності
  Duration: 25 min
  ✓ Запитати, як людина описує свій досвід самотності
  ✓ Пояснити різницю між соціальною ізоляцією (об'єктивний стан) і самотністю (суб'єктивне відчуття)
  ✓ Розповісти, що самотність — це сигнал, а не вирок
  ✓ Визнати, що це поширена проблема, яка не має соромити

Session 2: Подолання негативного мислення
  Duration: 25 min
  ✓ Пояснити, що самотність часто супроводжується негативними думками
  ✓ Дослідити типові переконання: "я нікому не цікавий", "мене відкинуть"
  ✓ Навчити техніці "спіймай і заміни": помітити негативну думку і замінити на більш реалістичну
  ✓ Пояснити, що люди часто переоцінюють ризик відторгнення

Session 3: Маленькі кроки — мікрозв'язки
  Duration: 20 min
  ✓ Пояснити концепцію "мікрозв'язків": швидка розмова з сусідом, привітання з баристою, коротке повідомлення
  ✓ Запропонувати обрати 1-2 мікрозв'язки на день
  ✓ Пояснити, що ці маленькі дії поступово знижують тривогу
  ✓ Вести щоденник мікрозв'язків (що зробив, як почувався)

Session 4: Дослідження інтересів
  Duration: 25 min
  ✓ Скласти список того, що людина любить робити (або любила колись)
  ✓ Дослідити: хобі, спорт, творчість, книги, фільми, волонтерство
  ✓ Для кожного інтересу подумати, де можна знайти однодумців
  ✓ Пояснити, що спільні інтереси — природна основа для дружби

Session 5: Волонтерство як шлях до спільноти
  Duration: 20 min
  ✓ Пояснити, що волонтерство не лише дає соціальні контакти, але й відчуття сенсу та приналежності
  ✓ Обговорити варіанти: притулки для тварин, продуктові банки, громадські організації
  ✓ Важливо: обрати те, що справді цікаво, а не "треба"
  ✓ Знайти 1-2 організації для початкового контакту

Session 6: Meet-up групи — знайомства за інтересами
  Duration: 20 min
  ✓ Розповісти про платформи: Meetup.com, Facebook-групи, Telegram-канали
  ✓ Дослідити, які групи існують у місті/країні людини
  ✓ Порадити почати з онлайн-зустрічей, якщо очні лякають
  ✓ Важливо: не зобов'язуватися відразу, просто прийти і подивитися

Session 7: Відновлення старих зв'язків
  Duration: 25 min
  ✓ Пояснити, що люди часто хочуть, щоб їм написали, але бояться писати першими
  ✓ Скласти список людей, з якими було добре колись
  ✓ Навчити простих фраз для початку:
  ✓ Пояснити, що навіть якщо не відповість — це не провал

Session 8: Соціальна тривога — як бути в нових місцях
  Duration: 25 min
  ✓ Пояснити стратегію "маленьких кроків" для людей із соціальною тривогою:
  ✓ Поступово збільшувати час перебування
  ✓ Практикувати дихання для заспокоєння перед виходом

Session 9: Правило 50 годин
  Duration: 20 min
  ✓ Розповісти про дослідження: для переходу від знайомства до дружби потрібно приблизно 50 годин спільного часу
  ✓ Пояснити, що це означає: регулярні зустрічі, спільні активності
  ✓ Допомогти спланувати, як створити ці "години" (регулярні клуби, спільні проєкти)
  ✓ Визнати, що не всі знайомства переростуть у дружбу — і це нормально

Session 10: Онлайн-спільноти як місток
  Duration: 20 min
  ✓ Пояснити, що онлайн-групи можуть бути безпечним способом практикувати соціальні навички
  ✓ Знайти групи за інтересами в соцмережах, Telegram, Discord
  ✓ Почати з читання, потім коментувати, потім знайомитися
  ✓ Обговорити, як перейти від онлайн до офлайн-зустрічей, якщо буде комфортно

Session 11: Якість, а не кількість
  Duration: 20 min
  ✓ Пояснити, що для щастя важливіша якість, а не кількість зв'язків
  ✓ Дослідити, які риси важливі в друзях для цієї людини
  ✓ Навчити розпізнавати "своїх" людей
  ✓ Визнати, що навіть 1-2 близькі друзі — це достатньо

Session 12: Підсумок — я вже не самотній(я)
  Duration: 20 min
  ✓ Повернутися до першої сесії — що змінилося у відчутті самотності?
  ✓ Вибрати 2-3 стратегії, які працюють найкраще
  ✓ Скласти план підтримки нових зв'язків на наступні місяці
  ✓ Визнати мужність у тому, щоб виходити з ізоляції
