🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Що я вмію і що люблю?
  Duration: 25 min
  ✓ Скласти список професійних навичок (освіта, досвід)
  ✓ Додати "приховані" навички (хобі, волонтерство, побутові вміння)
  ✓ Визначити, що приносить задоволення
  ✓ Запитати: "За що вас хвалили? За чим до вас звертаються?"

Session 2: Які бізнес-моделі підходять саме тобі?
  Duration: 30 min
  ✓ Розповісти про основні типи:
  ✓ Для кожної навички з сесії 1 підібрати 1-2 моделі
  ✓ Обрати 1-2 моделі для подальшого аналізу

Session 3: Чи є на це попит?
  Duration: 25 min
  ✓ Знайти конкурентів: хто вже пропонує подібні послуги?
  ✓ Проаналізувати їхні пропозиції: ціни, переваги, слабкі місця
  ✓ Пошукати в соцмережах і на форумах: чи питають люди про такі послуги?
  ✓ Визначити свою унікальність: чим ви будете відрізнятися?

Session 4: Створюємо "кворк" — готову пропозицію
  Duration: 30 min
  ✓ Пояснити концепцію "кворку" як готового продукту на полиці
  ✓ Створити заголовок: "Розроблю логотип для кав'ярні", а не "Зроблю дизайн"
  ✓ Написати детальний опис: що входить, обсяг, терміни, формати
  ✓ Визначити базову ціну
  ✓ Створити 3-5 додаткових опцій (терміновість, додаткові правки, розширений функціонал)

Session 5: Додаткові опції — секрет збільшення прибутку
  Duration: 20 min
  ✓ Пояснити, що часто дохід від опцій перевищує основний
  ✓ Придумати опції для свого кворку:
  ✓ Створити пакети: "Стартовий", "Бізнес", "Преміум"
  ✓ Пояснити, як це спрощує вибір для клієнта

Session 6: Де шукати клієнтів? (Безкоштовні канали)
  Duration: 25 min
  ✓ Соціальні мережі: Instagram, Facebook, LinkedIn, TikTok
  ✓ Фріланс-біржі: Upwork, Fiverr, Freelancehunt, Kwork
  ✓ Локальні групи: OLX, місцеві Facebook-спільноти
  ✓ Особисті зв'язки: друзі, знайомі, колишні колеги
  ✓ Створити профілі на 2-3 платформах

Session 7: Як писати, щоб купували?
  Duration: 20 min
  ✓ Пояснити: клієнт купує результат, а не процес
  ✓ Приклади:
  ✓ Використовувати цифри: "зроблю 5 макетів за 2 дні"
  ✓ Додати заклик до дії: "Напишіть мені, щоб обговорити"

Session 8: Перші клієнти — як не боятися?
  Duration: 20 min
  ✓ Пояснити, що всі проходять через це
  ✓ Запропонувати почати з друзів або бартеру (обмін послугами)
  ✓ Порадити взяти перше замовлення за нижчою ціною заради відгуку
  ✓ Нагадати: "Спочатку зробіть так, щоб ідея існувала, а потім робіть її хорошою"

Session 9: Відгуки — валюта фрілансера
  Duration: 15 min
  ✓ Пояснити, що 10 відгуків змінюють статус на "Продвинутий"
  ✓ Ввічливо просити клієнта залишити відгук після роботи
  ✓ Використовувати скріншоти відгуків у соцмережах
  ✓ Відповідати на відгуки, навіть негативні

Session 10: Фінансова дисципліна з першого дня
  Duration: 20 min
  ✓ Пояснити важливість окремого рахунку для бізнесу
  ✓ Враховувати комісії платформ (наприклад, 20% на Kwork)
  ✓ Відкладати на податки (якщо зареєстровано)
  ✓ Реінвестувати прибуток у розвиток

Session 11: Масштабування — коли і як?
  Duration: 20 min
  ✓ Ознаки готовності: стабільний потік замовлень, черга, фізична втома
  ✓ Варіанти: підвищити ціни, найняти помічників, автоматизувати
  ✓ Перехід до дорожчих послуг
  ✓ Поступове збільшення, без ризикованих кроків

Session 12: Підсумок — ти вже в дорозі
  Duration: 20 min
  ✓ Повернутися до першої сесії — що змінилося
  ✓ Вибрати 3 головні кроки на наступний місяць
  ✓ Скласти графік публікацій/пошуку
  ✓ Визнати, що навіть старт — це перемога
