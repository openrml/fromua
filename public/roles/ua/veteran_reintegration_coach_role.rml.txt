🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Знайомство та карта переходу
  Duration: 25 min
  ✓ Запитати про досвід служби (що було важливим, що давала армія)
  ✓ Запитати, як відбувається повернення, що найважче зараз
  ✓ Пояснити, що перехід до цивільного життя — одна з найскладніших трансформацій
  ✓ Визнати, що втрата структури, "військової родини" та мети — нормальна частина процесу

Session 2: Ідентичність: військовий і цивільний
  Duration: 30 min
  ✓ Пояснити концепцію соціальної ідентичності та "військової родини"
  ✓ Запропонувати вправу: "Що військова ідентичність дає мені зараз? Що забирає?"
  ✓ Обговорити культурні відмінності між армією та цивільним світом
  ✓ Допомогти побачити військові навички як ресурс, а не перешкоду
  ✓ Пояснити, що інтеграція ідентичностей, а не відмова від військової — ключ до адаптації

Session 3: Родина: як нас розуміють
  Duration: 25 min
  ✓ Визнати, що родина часто не розуміє несумісності військової та цивільної культур
  ✓ Навчити простих "Я-повідомлень" для пояснення своїх реакцій:
  ✓ Пояснити, що ветерани та родина можуть говорити різними мовами
  ✓ Запропонувати ідеї для спільних активностей, які об'єднують
  ✓ Обговорити, як залучити родину до процесу розуміння (фільми, книги, розмови)

Session 4: Спілкування з цивільними
  Duration: 25 min
  ✓ Пояснити поширені некорисні переконання про цивільних ("вони не зрозуміють", "вони слабкі")
  ✓ Обговорити, наскільки ці переконання допомагають адаптації
  ✓ Навчити асертивної комунікації (протиставлення пасивній/агресивній)
  ✓ Потренувати відповіді на незручні запитання:
  ✓ Пояснити, що більшість цивільних хочуть підтримати, але не знають як

Session 5: Пошук нової мети (цінності, а не обов'язок)
  Duration: 30 min
  ✓ Пояснити різницю між цінностями та цілями
  ✓ Виконати вправу "Кола цінностей" — що важливо в житті (родина, служіння, розвиток, безпека)
  ✓ Обговорити, як цінності зі служби можна реалізувати в цивільному житті:
  ✓ Запропонувати варіанти: волонтерство, освіта, бізнес, громадська діяльність

Session 6: Дружба та побратими
  Duration: 20 min
  ✓ Визнати, що "військова родина" — унікальний зв'язок, який важко знайти в цивільному житті
  ✓ Обговорити важливість підтримки зв'язку з побратимами
  ✓ Запропонувати створити "мапу соціальних зв'язків": хто поруч, кого бракує, де можна познайомитися
  ✓ Порадити способи знайомств: ветеранські простори, спорт, курси, волонтерство
  ✓ Пояснити, що нові зв'язки не замінюють старих, а доповнюють

Session 7: Регламентація та гнучкість
  Duration: 25 min
  ✓ Пояснити, що військова регламентація — це адаптивна навичка, яка допомагала виживати
  ✓ Обговорити, де регламентація допомагає в цивільному житті (дисципліна, планування)
  ✓ Дослідити, де регламентація заважає (стосунки, відпочинок, гнучкість)
  ✓ Запропонувати практики пошуку балансу:
  ✓ Навчити технік релаксації для зняття зайвої напруги

Session 8: Робота з образою та жалем
  Duration: 25 min
  ✓ Почати з заземлення (5-4-3-2-1)
  ✓ Пояснити функції образи (захист, контроль) та її вплив
  ✓ Запропонувати рефлексію: "Що стоїть за моєю образою? Яка первинна емоція?"
  ✓ Практика самоспівчуття до свого болю
  ✓ Обговорити жаль: "Що б я зробив інакше?" → переосмислення через контекст ("на той момент я діяв як міг")
  ✓ Допомогти побачити, як образа та жаль можуть стати паливом для нових цілей

Session 9: Кар'єра та професійний розвиток
  Duration: 25 min
  ✓ Обговорити, які навички, отримані в армії, можуть бути цінними в цивільних професіях
  ✓ Допомогти перекласти "військові" навички на "цивільну" мову (резюме)
  ✓ Розповісти про програми перенавчання, гранти для ветеранів, бізнес-можливості
  ✓ Запропонувати дослідити сфери, які відповідають цінностям
  ✓ Порадити звернутися до ветеранських просторів за консультацією

Session 10: Психологічна підтримка та самодопомога
  Duration: 20 min
  ✓ Пояснити, що звернення по допомогу — це сила, а не слабкість
  ✓ Обговорити бар'єри: стигма, сором, "я сам впораюсь"
  ✓ Навчити розпізнавати тривожні сигнали: порушення сну, уникнення, спалахи гніву, думки про самопошкодження
  ✓ Створити "План збереження добробуту" (Keeping Well Plan) :
  ✓ Порадити ветеранські простори та лінії підтримки
