🗺️ STEP 5: JOURNEY SESSIONS

Session 1: Діагностика — де ми зараз?
  Duration: 25 min
  ✓ Запитати про причину відстані (війна, робота, навчання) і тривалість
  ✓ Визначити, чи є спільне бачення "фінішу" дистанції

  ✓ Виявити основні болючі точки (самотність, ревнощі, брак спілкування)

Session 2: Спільне бачення майбутнього
  Duration: 30 min
  ✓ Пояснити важливість "фінішної прямої" для стосунків на відстані
  ✓ Запропонувати обговорити з партнером три питання:
  ✓ Визнати, що обставини можуть змінюватися — план має бути гнучким
  ✓ Порадити регулярно повертатися до цих питань

Session 3: Час разом — мистецтво бути поруч
  Duration: 25 min
  ✓ Пояснити потребу в балансі між "інтенсивністю" і "розслабленням"
  ✓ Запропонувати планувати як активні пригоди, так і час "просто поруч"
  ✓ Наголосити, що сидіти поруч у тиші — це теж якісний час
  ✓ Обговорити, як уникати тиску "ідеальних вихідних"
  ✓ Порадити після зустрічі обговорити, що було найкращим

Session 4: Перед розлукою — як пережити прощання
  Duration: 20 min
  ✓ Визнати, що смуток перед розлукою — нормальний
  ✓ Порадити не уникати цих почуттів, а проживати їх разом
  ✓ Запропонувати підтвердити плани наступної зустрічі перед від'їздом
  ✓ Порадити після від'їзду не ізолюватися, а звертатися до друзів/родини
  ✓ Обговорити створення маленького ритуалу прощання

Session 5: Час нарізно — ритуали зв'язку
  Duration: 25 min
  ✓ Пояснити, що ритуали створюють передбачуваність і безпеку
  ✓ Запропонувати ідеї спільних активностей:
  ✓ Допомогти обрати 2-3 ритуали, які підходять саме цій парі

Session 6: Комунікація — глибина vs частота
  Duration: 25 min
  ✓ Пояснити, що не існує єдино правильної частоти спілкування
  ✓ Допомогти обговорити потреби обох партнерів:
  ✓ Навчити техніки "глибоких" розмов замість поверхневих "як справи"
  ✓ Порадити планувати "побачення" на відеодзвінку

Session 7: Ревнощі та невпевненість
  Duration: 25 min
  ✓ Пояснити, що ревнощі — нормальна емоція, але важливо, що ми з нею робимо
  ✓ Допомогти дослідити тригери: що саме викликає ревнощі?
  ✓ Розрізнити: це про недовіру до партнера чи про мою невпевненість?
  ✓ Навчити технік самозаспокоєння в моменти тривоги
  ✓ Порадити, як говорити про ревнощі без звинувачень
  ✓ Обговорити важливість прозорості (але не тотального контролю)

Session 8: Сексуальна інтимність на відстані
  Duration: 20 min
  ✓ Визнати, що сексуальна фрустрація — нормальна частина LDR
  ✓ Запропонувати обговорити з партнером комфортні формати:
  ✓ Наголосити на важливості згоди, безпеки, комфорту
  ✓ Пояснити, що не всім це підходить — і це нормально

Session 9: Індивідуальне життя — якір стабільності
  Duration: 20 min
  ✓ Пояснити, що здорові стосунки = дві цілісні особистості
  ✓ Допомогти дослідити, які сфери життя "просіли" через фокус на стосунках
  ✓ Запропонувати ідеї для розвитку: хобі, спорт, навчання, друзі
  ✓ Порадити заохочувати партнера до його/її власних активностей
  ✓ Обговорити, як ділитися враженнями від "окремого" життя

Session 10: Підсумок і план підтримки
  Duration: 20 min
  ✓ Повернутися до початкових викликів і оцінити прогрес
  ✓ Вибрати 3-5 стратегій, які працюють найкраще
  ✓ Скласти план на наступні місяці (ритуали, зустрічі, комунікація)
  ✓ Визначити "червоні прапорці", коли може знадобитися парна терапія
  ✓ Визнати силу і стійкість пари
