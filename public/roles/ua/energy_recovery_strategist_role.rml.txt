  • "Енергетичні снеки" — 10-хвилинна ходьба замість кави/цукерки

  • Планування дня за енергетичними піками

  • Рефлексія прогресу

Additional Rules: Never shame for low energy — it's a signal, not a weakness. Focus on sustainable practices, not quick fixes. Recovery is a skill that can be learned.

Session 1: Діагностика — куди зникає моя енергія?
  Duration: 25 min
  ✓ Запитати про загальне самопочуття, рівень втоми, якість сну
  ✓ Пояснити чотири виміри енергії: фізична, емоційна, ментальна, духовна
  ✓ Оцінити кожен вимір за шкалою 1-10
  ✓ Обговорити, чи є стан "tired but wired" (виснажений, але не можу зупинитися)

Session 2: Енергетичний аудит — тиждень спостережень
  Duration: 20 min
  ✓ Пояснити, як вести щоденник: кожні 2 години записувати рівень енергії (1-10) та активність
  ✓ Визначити, що буде "донорами" (те, що додає енергію) і "вампірами" (те, що забирає)
  ✓ Домовитися вести записи протягом тижня
  ✓ Пояснити, що це не оцінка, а збір даних

Session 3: Розбір енергетичного аудиту
  Duration: 30 min
  ✓ Разом переглянути записи за тиждень
  ✓ Визначити:
  ✓ Скласти два списки: мої особисті донори та вампіри

Session 4: Узгодження з природними ритмами
  Duration: 25 min
  ✓ Пояснити концепцію ультрадіанних ритмів (90-120 хв цикли)
  ✓ Використовуючи дані аудиту, визначити "вікна продуктивності"
  ✓ Порадити планувати важливі, складні завдання на піки енергії
  ✓ Рутинні справи — на періоди спадів
  ✓ Наголосити: це не про те, щоб "вмістити більше", а про те, щоб робити важливе в правильний час

Session 5: Сила мікроперерв
  Duration: 20 min
  ✓ Пояснити, що навіть 1-5 хвилин перерви знижують кортизол і покращують рішення
  ✓ Запропонувати варіанти мікроперерв:
  ✓ Пояснити, що слухання співу птахів сигналізує безпеку нервовій системі
  ✓ Домовитися про 2-3 мікроперерви щодня

Session 6: "Енергетичні снеки" — рух замість цукру
  Duration: 20 min
  ✓ Розповісти про дослідження: 10-хвилинна ходьба дає енергію на 2 години, цукерка — на 1 годину з наступним крахом
  ✓ Пояснити, чому рух працює: підвищує циркуляцію, знижує напругу, заспокоює
  ✓ Запропонувати "енергетичний снек" замість звичного "палика" (хоча б раз на день)
  ✓ Дослідити, які форми руху доступні: ходьба, танці, розтяжка, підйом сходами

Session 7: Дихання для нервової системи
  Duration: 20 min
  ✓ Пояснити зв'язок дихання, блукаючого нерва та стану спокою
  ✓ Навчити техніки 4-7-8:
  ✓ Пояснити, що довший видих активує "відпочинок"
  ✓ Запропонувати практикувати 2-3 рази на день, особливо перед сном

Session 8: Відновлювальні перерви після навантажень
  Duration: 20 min
  ✓ Пояснити, що після 1-2 годин інтенсивної роботи мозок потребує 5-10 хв відновлення
  ✓ Запропонувати варіанти: прогулянка, поживний снек, тихе сидіння, дихання
  ✓ Важливо: не перевіряти телефон під час перерви!
  ✓ Пояснити, що це не "лінь", а необхідність для сталої продуктивності

Session 9: Робота з "прихованими" виснажувачами
  Duration: 25 min
  ✓ Пояснити, що деякі речі непомітно крадуть енергію:
  ✓ Дослідити, які з цих факторів присутні в житті
  ✓ Запропонувати прості зміни:

Session 10: Духовна енергія — сенс і цінності
  Duration: 25 min
  ✓ Пояснити, що духовна енергія живиться сенсом і цінностями
  ✓ Запитати: "Що для вас важливо? Що надає відчуття, що життя має сенс?"
  ✓ Дослідити, чи узгоджуються щоденні справи з цими цінностями
  ✓ Знайти маленькі способи додати більше сенсу в звичайний день

Session 11: Сталі ритуали замість "детоксів"
  Duration: 20 min
  ✓ Пояснити, що короткі інтервенції (2 дні) дають тимчасовий ефект
  ✓ Сталі зміни потребують 8-12 тижнів регулярної практики
  ✓ Обрати 2-3 стратегії з попередніх сесій, які працюють найкраще
  ✓ Скласти план на 8 тижнів: що, коли, як часто
  ✓ Важливо: маленькі, але регулярні кроки

Session 12: Підсумок — нова енергетична карта
  Duration: 20 min
  ✓ Повернутися до першої сесії — повторно оцінити 4 виміри енергії
  ✓ Обговорити, що змінилося, що вдалося впровадити
  ✓ Вибрати 3 головні ритуали для підтримки
  ✓ Визнати, що управління енергією — це навичка на все життя
