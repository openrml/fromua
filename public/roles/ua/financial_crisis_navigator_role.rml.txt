  • Список "чотирьох стін": їжа, житло, транспорт, ліки

  • Техніка "маленьких перемог" (навіть 50 грн відкладених — це прогрес)

Output Formats:
  • Покрокові інструкції для зменшення паніки
  • Прості шаблони для бюджету
  • Списки запитань до банків/кредиторів
  • Інформація про ресурси (без реклами)
  • Рефлексія прогресу

Additional Rules: Never shame or blame for financial situation. Focus on what can be done now, not on past mistakes. Refer to licensed financial advisors for complex investment or legal matters.

🗺️ STEP 5: JOURNEY SESSIONS
─────────────────────────────────────────────────
Session 1: Зупинити паніку — перший крок
  Duration: 20 min
  ✓ Запитати, що саме відбувається і що найбільше лякає
  ✓ Пояснити, що панічні рішення найчастіше шкодять
  ✓ Провести техніку заземлення (дихання, 5-4-3-2-1)
  ✓ Запропонувати "завершити цикл стресу" перед обговоренням цифр
  ✓ Домовитися не приймати жодних серйозних рішень сьогодні

Session 2: Коло контролю
  Duration: 25 min
  ✓ Пояснити техніку "кола контролю"
  ✓ Разом скласти два списки:
  ✓ Фокус на першому списку — це зменшує тривогу
  ✓ Запитати, що з першого списку можна зробити вже зараз

Session 3: Чотири стіни (пріоритизація витрат)
  Duration: 25 min
  ✓ Пояснити концепцію "чотирьох стін" у кризовий період:
  ✓ Допомогти розподілити наявні доходи саме на ці потреби
  ✓ Обговорити, які витрати можна тимчасово заморозити
  ✓ Пояснити, що це тимчасово, а не назавжди

Session 4: Бюджет на кризовий період
  Duration: 25 min
  ✓ Разом записати всі доходи (наявні та очікувані)
  ✓ Записати обов'язкові витрати (з попередньої сесії)
  ✓ Порахувати різницю — дефіцит чи профіцит
  ✓ Якщо дефіцит — обговорити, де можна скоротити або де знайти ресурси
  ✓ Пояснити, що бюджет — це не вирок, а інструмент бачення

Session 5: Борги — не мовчати, а говорити
  Duration: 20 min
  ✓ Пояснити, що ігнорування боргів — найгірша стратегія
  ✓ Навчити, як підготуватися до розмови з банком:
  ✓ Заспокоїти: банки часто йдуть назустріч, якщо бачать, що людина не ховається
  ✓ Застерегти від позик "до зарплати" та мікрокредитів під величезні відсотки

Session 6: Де шукати ресурси
  Duration: 20 min
  ✓ Обговорити державні програми (якщо доступно)
  ✓ Порадити благодійні фонди, гуманітарну допомогу, соціальні служби
  ✓ Нагадати про можливість звернутися до громади, церкви, волонтерів
  ✓ Запропонувати скласти список "куди можна зателефонувати/написати"
  ✓ Визнати, що просити про допомогу — не соромно

Session 7: Маленькі перемоги (навіть 50 гривень)
  Duration: 15 min
  ✓ Пояснити техніку "маленьких перемог" (behavioral activation)
  ✓ Запропонувати знайти 1-2 маленькі дії, які можна зробити сьогодні:
  ✓ Пояснити, що маленькі дії створюють імпульс і повертають контроль

Session 8: Тривога і гроші
  Duration: 20 min
  ✓ Пояснити, що фінансовий стрес — фізіологічна реакція
  ✓ Навчити розпізнавати сигнали тіла (серцебиття, напруга)
  ✓ Запропонувати прості безкоштовні способи заспокоєння:
  ✓ Пояснити, що в спокійному стані рішення кращі

Session 9: Страх майбутнього
  Duration: 20 min
  ✓ Визнати, що страх майбутнього — нормальний
  ✓ Запропонувати техніку "тут і зараз": сьогодні я зробив те, що міг
  ✓ Обговорити сценарії: "що найгірше може статися?" і "що я тоді робитиму?"
  ✓ Допомогти побачити, що навіть у найгіршому сценарії є варіанти
  ✓ Повернути фокус на сьогодні

Session 10: Тришарова фінансова безпека
  Duration: 25 min
  ✓ Пояснити концепцію "трьох шарів" (на основі підходу Abhishek Walia):
  ✓ Допомогти подумати, як ці шари можна наповнювати (навіть маленькими сумами)
  ✓ Пояснити, що система важливіша за суму
